## 1. 학운 종합 점수 (티어)

### 1-1. 점수 범위 (v7 4-Layer)

**4-Layer 구조** (2026-05-22 v7 — Agent 명리 리서치 + 14 시그너):
- **Layer 0** Boolean — 학자형 본질 라벨 (TRUE/FALSE)
- **Layer 1** 명식 본질 (~60점)
- **Layer 2** 신살·귀인 (0~20점) 🆕 신규 카테고리
- **Layer 3** 운 점수 (0~20점)
- **Layer 4** 페널티 (−35~0)
- **총점** = max(0, Layer1+2+3+4) → **0~100점**

| 구분 | 값 |
|---|---|
| 이론상 최대 | **+100** |
| 실측 분포 (N=56,988) | **0 ~ 91** |
| 실측 평균 / stddev | **25.33 / 17.01** |
| Percentile | p10=0 / p25=12 / **p50=25** / p75=37 / p90=49 / p95=55 / **p99=64** / p99.9=73 |
| 0점 sample | 14.88% (학자형 본질 ✗ 영역) |

#### Layer 0: 학자형 본질 Boolean

```
isScholar = (관인상생 OR 학자형격국 narrow OR 양인+제왕+학자귀인≥2)
            AND 학자귀인 ≥ 1
```

8명 calibration 변별력 **precision 100% + recall 100%** (Rule 5 — 8-sample-signer-audit.ts 검증).

| # | 시그너 | 가산 | 조건 |
|---|---|---|---|
| 3-1 | **청소년기 대운 (16~22세 정인·정관)** | **+15 / +8 / +4** | youthLuck ≥3 / ≥1 / 0 |

| # | 시그너 | 가산 | 조건 |
|---|---|---|---|

#### 최종 점수

```
total = max(0, min(100, Layer1 + Layer2 + Layer3 + Layer4))
```

**제거**: 일간 강도 균형 [−2, +4] (Eugene 신왕 7이 페널티 받던 구조 해소)

**신규 5개**:
- 자립 학자형 콤보 +12 (Layer 1)
- 일주 통근 +5 (Layer 1)
- 천을귀인 +6/4 (Layer 2)
- 천덕+월덕 동시 +5 / 삼귀구비 +5 / 삼기귀인 +5 (Layer 2)

**가중치 재조정**: 관인상생 콤보 18→15, 격국 15→12, 학자귀인 12/8/5→10/7/4, 인성 10/5→8/4, 학자형 양인 7→5, 청소년 대운 20/10/5→15/8/4, 관성 단독 10/5→5/3

**신약 페널티 완화**: 정인격·편인격이면 −15 → −5 (자평진전 합의)

### 1-6. 부모 환경 조정 (`parentAdjust`)

부모 사주 입력 시 ±2 가산 한도 내에서 베이스 티어 조정.

| 조건 | 가감 |
|---|---|
| 어머니 일간 → 자녀 정인·편인 작용 | +1 (학문 받쳐줌) |
| 어머니 일간 → 자녀 정재·편재 작용 | -1 (인성 극, 학업 견제) |
| 아빠 일간 → 자녀 정인·편관 작용 | +1 (성장 자극, 절반 가중치) |
| 아빠 일간 → 자녀 비견·겁재·정재·편재 | 0 (자원 분산 가능, 절반 가중치) |
| **한도** | **±2** |

부모 미입력(현재 기본)이면 parentAdjust = 0 → 베이스 티어 = 최종 티어.

## 2. 학운 10가지 특성 점수 (UI 카드)

§0 직후 노출되는 시각 hook. 각 항목 0~100 점수 + 상위 N% 표시.

### 2-1. 정규화 공식

- raw 점수 = base 40 + 시그너 weight 합산 (clamp 0~100)
- normalized = percentile stepwise 매핑 (상위 1%→99, 상위 15%→90, 상위 30%→78, 상위 50%→62)
- 같은 percentile 사용자는 같은 점수 → 일관성

분포 시뮬레이션: 2008~2020 × 365일 × 12시간 슬롯 × 2성별 = **113,976 sample**

|---|---|---|

| 끈기·꾸준 | 81.8 | 13.1 |
| 사고력 | 62.4 | 11.5 |
| 표현·발표 | 65.6 | 16.1 |

## 4. 점수 시스템 명리적 근거

### 4-1. 한국 명리학 통설 기반

- **관인상생**: 관성(시험·자격) + 인성(학문) 흐름 = 학자형 핵심 [명리학회·다시 배우는 사주명리·플러스운세력 김현희 칼럼]
- **관인상생 유연화**: 인성 0이라도 관성≥2 + 학문 신살 + 삼합이 결집하면 인성 자리 간접 보완 (한국 명리 합의 — 합·삼합이 천간 부재를 메움)
- **자립 학자형 패턴**: 정인·편인·정관격 + 일지 건록·제왕 + 비겁 ≥2 = POSTECH·서울대 이공계 1티어 패턴 (정은광 박사 — "학당귀인·문곡 + 자립 의지" 결합)
- **학자형 4귀인 (문창·학당·문곡)**: 문창=실전 표현·논술, 학당=장생지 학자/교수 트랙, 문곡=편인 건록지 연구·예술. 천을귀인은 메타 길성으로 student-traits에서 별도 활용
- **신왕신약**: 일간 강해야 인성을 흡수 — sajustudy·forceteller 신강신약 표준
- **양인격·건록격·비견격 (추진력형)**: 학자형 ✗이지만 격국 명확 + 신왕 + 비겁 강이면 자기 의지로 입시 돌파 (브런치 healerlee 격국론)
- **재극인(財剋印)**: 재성 과다가 인성을 극 → 학업 견제. 표준 학업 견제 패턴 (다시 배우는 사주명리)
- **청소년기 대운 (6~22세)**: 인성·관성 대운 = 학문·시험 ↑, 재성 대운 = 학업 견제. 사주 원국보다 대운이 흐름 결정 (플러스운세력 대운·세운 표준)
- **화개살**: 예술·창작 가장 강한 시그너
- **천의성·백호대살**: 의약·치과 본질

### 4-2. 분포 시뮬레이션 모집단

2008~2020년 양력 × 365일 × 12시간 슬롯(2시간 단위) × 남·녀 = 113,976 조합. 일진·시진은 균등 분포라 한국 모집단과 큰 편향 ✗.
