# DETECTOR_CANDIDATES_V4 — 학파 2개 이상 검증을 통과한 새 시그너 후보

> 2026-05-24 작성. V3 calibration loop (180 시나리오 / 75 detector pool) best totalGap 55 정체 문제에 대응. 9명 sample의 명리적 핵심 패턴을 재분석하고, **학파 2개 이상 인용**이 가능한 새 detector 20-30개를 제안한다.
>
> 본 문서의 출력은 V4 calibration loop의 후보 pool 확장에 직접 활용된다. ad-hoc cherry-pick 방지를 위해 검증 통과 못 한 후보는 §4에 별도 보관.

---

## 0. 머리말

### 0.1 목적

V3 calibration loop는 다음 한계에 부딪쳤다.

- **정환(정재격 + 포항공대)**: 학자형 격국 narrow에서 제외되어 Layer 1 본질에서 깎임. 시스템상 +45 점수는 청소년 대운 강 + 관인상생 + 학당귀인이 상쇄해 매우 강 분류를 살렸으나, **격국 차원의 학자형 인정 부재**가 가장 큰 격차 원인.
- **두흥(편관격 + 경북대 치대)**: 편관격이 학자형 narrow에서 명시적 제외(의·법·외과 트랙 분리). 묘유충 + 식상 부재 + 일지 사 → +9 약함. **편관격 + 인성 ≥ 2 + 관인상생인 경우의 학자형(살인상생)** 시그너 부재.
- **승희(상관격 + 인성 3 + 국민대 시각디자인)**: 상관격은 학자형 격국 ✗. 그러나 인성 3 동반 → 상관패인(傷官佩印) 명리 합의는 학자형. 시스템은 청소년 대운 학자형 강만 +15 잡고 격국 차원은 평가 ✗.
- **Eugene(정인격 + POSTECH)**: 자립 학자형 +12로 일부 잡혔으나 청소년 대운이 학자형 ✗ + 신왕 페널티 회피 외 보강 ✗. **편인격·정인격 + 비겁왕 + 일지 통근 패턴의 강화**가 약함.
- **영진(상관격 + 인성 1 + 경희대 경영)**: 시스템 한계 = 외부 의지(연예인 적성·전교 회장). artsScore 강 5로 분리 매핑. **학운 시그너로는 본질적으로 약중 — V4에서도 영진을 위한 ad-hoc 시그너는 금지**.

### 0.2 검증 기준

각 후보 detector는 다음 3관문을 모두 통과해야 한다.

1. **학파 인용 ≥ 2개** — 자평진전·삼명통회·연해자평·적천수·자평수언·김기승 「명리직업상담론」·KCI 사주 학자형 논문 등 정평 학파 중 둘 이상에서 명시.
2. **9 sample 중 2명 이상 발동** — 한 명만을 위한 cherry-pick 시그너 금지. 단 페널티성 시그너는 1명 발동도 허용(이미 학자형 부재 콤보가 그 패턴).
3. **방향성 정합** — 학자형 본질의 명리적 신호여야 함. 직업 분기(arts·의·법) 시그너는 별도 모듈(arts-score·medical-score)로 이관.

### 0.3 출력 형식

각 후보는 다음 6항목을 모두 채운다. 한 항목이라도 검증 ✗이면 §4 보류 섹션으로.

```
### detector ID
- 명칭 (한글·한자)
- 발동 조건 (코드로 표현 가능한 boolean)
- 학파 인용 (≥ 2)
- 잡을 sample (9명 중 누구·왜)
- 가설 weight
- 학자형 본질 정합 (Layer 1·2·3 중 어디)
```

## 1. 9 sample 명리적 핵심 패턴 재정리

각 sample의 사주를 다시 펼쳐 **누락된 학자형 신호**를 식별. computeManse 실측 출력 기준.

### 1.1 Eugene (정인격, POSTECH, hagun 36)

```
y=을묘 m=무자 d=갑인 h=을해
gyeokguk: 정인격
counts: bi=4 sik=0 jae=1 gwan=0 in=2
gwaninSang: false (관성 0)
gui: hakdang=1
unsung: month=목욕 day=건록
shensha: 도화·양인·현침·천의·암록 (학자형 ✗ — 도화·양인 우세)
daeun 6-22: 9세 상관/편인, 19세 식신/편재 (학자형 ✗·역풍 1)
```

**핵심 패턴**:
- **정인격 + 일지 건록 + 비겁 4** = 자평진전 「정인격은 신왕을 좋아한다(正印格喜身旺)」 정평. 시스템 자립 학자형 콤보(+12)로 일부 잡힘.
- 식상 0 = **인성 과다(印多)**. 자평진전 「인다신왕은 식상 없으면 게으름·자기 안주」 패널티 가능성, 그러나 실제 성취가 1티어 → V4에서 페널티 ✗ 권장.
- **청소년 대운 학자형 ✗** = youthLuck = 0 (상관·편인=+1−1, 식신·편재=+1−1 ≈ 0). 명식 본질만으로 +36 달성. 시스템 정합.

**누락 신호**: (a) 정인격 + 일지 건록 + 인성 ≥ 2의 **삼중 통근** — 자평수언 「신왕한 정인격은 학문이 자기 안에 갖춰진 형태」. (b) **암록** (Eugene만 보유) — 김기승은 암록을 "숨은 귀인"으로 학업·시험에 보조.

- **상관격 + 인성 3** = 자평진전 「傷官佩印 — 상관패인」 정평. **학자형 격국 narrow 미포함의 결정적 누락**. 시스템 32점은 청소년 대운 강 +15 + 학자귀인 +10 + 인성 ≥ 2 +8 + 천을·천덕 등으로 도달했으나, 격국 본질 차원 평가 ✗.

- 일지 오(사) + 식상 2 = 식상 활발 + 신약 → 디자인 트랙 정합.

**누락 신호**: (a) **상관패인 콤보** = 상관격 AND 인성 ≥ 2. (b) **자형 다중** (≥ 2) 페널티 후보 — 학업 안정성 측면.

- **백호대살 + 화개 + 일지 사(약)** = 흉살 누적. 학업 시기 페널티 후보.

### 5.3 검증 지표

- **totalGap**: 9 sample 점수 — expected hagunScore 차이 합 (V3 best 55에서 ≤ 40 목표)
- **1티어 5명 매우 강 분류율**: 5/5 유지
- **승희 분류**: 강(2~3) 유지 또는 매우 강(1~2) 격상 (디자인 4티어와 학운 본질 강 분리 정합)
- **두흥 분류**: 중(4~5) 목표 (외부변수 sample, +18 추정으로 중상 도달이면 정합)
- **영진·와이프 분류**: 약중(7~8) 유지 (학자 본질 ✗ 정합)

### 5.4 ad-hoc 방지 체크리스트

V4 시뮬 중 새 후보 추가 시:

1. ☐ 학파 ≥ 2개 인용 (자평진전·삼명통회·연해자평·적천수·자평수언·김기승·KCI 중)
2. ☐ 9 sample 중 ≥ 2명 발동 (또는 페널티는 1명도 가능하지만 명리 합의 강력)
3. ☐ 학자형 본질 정합 (방향성·arts·의 트랙은 별도 모듈)
4. ☐ 영진을 위한 단독 시그너 ✗
5. ☐ §2의 20개 중 V4 시뮬 best 결과로 채택된 것만 prod 코드(hagun-tier.ts)에 반영

### 5.5 LOOCV 검증 권장

V4 best config 선정 후 reuse `eval-hagun-loocv.ts` 패턴으로 LOOCV 재실행. cutoff variance + 1티어 분류율 안정성 측정. 자유도 ~30 시그너 × 9 sample은 여전히 과적합 영역이므로 out-of-sample 일반화 능력은 미검증임을 명시.
