### 아직 안 시도된 방향 (V3 후보)
- **개별 sample 강화 deeper fine-tuning** — V2 Top 3 weight를 기준점, 개별 sample gap 분석 기반 미세 조정
- **격국별 페널티/보너스 차등** — 양인격에는 신살 보너스, 정재격에는 base 보너스
- **사주 강약 (사주 종합 점수) 기반 페널티 약화** — 강한 사주는 페널티 자동 약화
- **세운 (1년 운) 가중** — 대운 외 입시 해당 년도 세운 시그너
- **충형해파 페널티 변별** — 청소년기 시기·강도별 차등
- **신살 가중치 단계별** — 천을 1개 vs 2개 vs 3개 (현재 binary)
- **자유도 ↓ — Top 3 weight set 평균 + Bayes 최적화**
