# Counterfactual 검증 — 학운 v7 시그너 신호 vs 무작위 사주

> 2026-05-23 작성. `scripts/eval-counterfactual.ts` 재현 가능.
>
> 목적: v7 학운 시스템이 "실제 사주 구조에 반응하는지" vs "어떤 사주에도 비슷한 점수를 주는지" 분리. LOOCV(일반화 검증)보다 논리적으로 우선하는 **신호 존재 검증**.

---

## 1. 동기

N=11 calibration에서 1티어 5명(홍규·정환·세형·윤수·상수)이 모두 매우 강(≥34) 통과. 그러나 이건 **시그너 신호의 결과인가, 시스템 구조 자체의 inflation인가** 구분 불가.

추가로 1티어 5명 중 4명이 1975-1976 cohort에 몰려 있음 (`docs/CALIBRATION_BIRTH_MONTH.md` confound 기록). cohort 효과를 신호로 오인할 가능성.

**Counterfactual 설계** (참고: BaZi-LLM 논문이 primary validation으로 사용):

- **A안 (sanity)**: 1900-2010 전체 random 1000개 → 시스템 전체 점수 분포 측정
- **B안 (cohort 통제)**: 1티어 5명 각각 ±2년 cohort 내 random 100회 × 5 = 500 → 시그너 신호 vs cohort 효과 분리

해석 가이드:
- B안 gap ≥ 10 → 시그너 신호 강함
- B안 gap 5-10 → 신호 약함·cohort 일부 기여
- B안 gap < 5 → 신호의 상당 부분이 cohort 효과 (재설계 검토 필요)

## 2. 결과 (Seed 42, youthLuck ×1.5 적용 후 — 2026-05-23 갱신)

### 2-1. 종합 비교

| 그룹 | N | 평균 | 1티어 실제 평균 대비 gap |
|---|---|---|---|
| **1티어 5명 실제** | 5 | **40.6** | — |
| **A안** (1900-2010 random) | 1000 | 25.62 | **15.0** |
| **B안** (cohort ±2 random) | 500 | 24.52 | **16.1** |

**핵심 관찰**:
- **A안 ≈ B안** (25.6 vs 24.5) → **cohort 효과 거의 없음**. 1975-1976년 cohort가 1900-2010 random보다 점수가 의미 있게 높지 않음.
- **B안 gap = 16.1점** → 1티어 5명이 동일 cohort random보다 평균 16점 높음. **시그너 신호 실재** (×2 시 18.1보다 약간 축소).
- **A안 gap = 15.0점** → 전체 random 대비로도 유사한 격차.

> **youthLuck ×2 → ×1.5 보수화 영향** (2026-05-23): 1티어 평균 43.4 → 40.6 (-2.8), B안 gap 18.1 → 16.1. 정환·세형 -7, 다른 3명 변동 없음. 신호 여전히 강 (gap ≥ 10).

### 2-2. 개별 1티어 sample × cohort 통제 (Seed 42, ×1.5 후)

| Sample | 실제 점수 | B안 cohort 평균 | gap | random 매우 강 비율 |
|---|---|---|---|---|
| **정환 (1975)** | 38 | 27.88 | **10.1 (최소)** | 40% |
| 홍규 (1976) | 36 | 23.23 | 12.8 | 27% |
| 윤수 (1975) | 38 | 22.89 | 15.1 | 26% |
| 상수 (1975) | 46 | 25.16 | 20.8 | 34% |
| **세형 (1975)** | **45** | 23.43 | **21.6** ⭐ | 27% |

- **세형(연대 의예)의 gap이 가장 큼** → 시스템이 의약·최상위 sample을 가장 강하게 인지 (×1.5 후도 anchor 유지)
- **정환 gap 10.1 (최소)** → ×2 → ×1.5 보수화의 비용. 점수 38은 cutoff 34에서 +4 마진, cohort gap 10.1은 1티어 중 가장 약한 신호
- 홍규·윤수의 gap이 작음 (12.8·15.1) → 매우 강 영역의 하단. **점수 자체로는 1티어 보장이 명확하나 random 대비 격차는 상대적으로 좁음**
- 정환의 cohort 평균(27.88)이 다른 4명보다 약간 높음 → 1975년 일부 월·일 조합이 시그너 hit 잘 됨 (small effect)

### 2-3. "매우 강(≥34)" cutoff의 false positive rate

| 그룹 | 매우 강 비율 (×1.5 후) |
|---|---|
| A안 random | 34.0% |
| B안 cohort random | 30.8% |

**중요한 발견**: **무작위 사주의 약 1/3이 "매우 강"으로 분류됨**.

해석:
- 1티어 sample이 random보다 평균 16점 높은 건 명백한 신호 ✓
- 그러나 **"매우 강" 라벨 자체는 random에서도 31-34% 발생** → 라벨링 위상은 "특별함"이 아니라 "통계적 상위 1/3"
- 1티어 5명의 평균(40.6)은 매우 강 영역의 **중상위** 위치. random 매우 강 sample(평균 50 정도 추정)과 비교 시 상대 위치 별도 분석 필요

## 3. 함의

### 3-1. 시스템 정당화 (긍정)

- **시그너 신호 실재 확정** ⭐
  - B안 gap 18점 = 동일 cohort 내에서도 1티어 sample이 명백히 분리됨
  - "v7이 무작위에도 비슷한 점수를 준다"는 비판 무력화
- **Cohort confound 해소** ⭐
  - A안 ≈ B안 (25.9 ≈ 25.3) → 1975-1976 cohort 효과가 신호의 주된 원인 ✗
  - 신호의 18점 중 약 17점은 **사주 구조(시그너 hit)에서 옴**
- **세형(연대 의예 1티어) gap 27.7점** = 시스템이 의예·최상위 tier sample을 가장 강하게 잡음 → medical-score 모듈 합리성

### 3-2. 표현 약화 작업의 정직성 (부정)

- **"매우 강" 라벨은 random에서도 1/3 발생** → "확실한 1티어" 단언 정직성 ✗
- 1티어 sample의 매우 강 영역 평균 위치(43.4)는 **상위 중상위** 수준, 최상위 아님
- 따라서 표현 톤 권고:
  - ✗ "확실한 1티어 학자형 강"
  - ✗ "타고난 학자 자리"
  - ✓ "학자형 시그너 4-5개 hit. 시스템이 관찰한 학자형 강 패턴"
  - ✓ "점수 ≥34는 무작위 사주의 1/3이 통과하는 영역이며, 1티어 sample의 평균(43)은 그 안에서 중상위"

### 3-3. Cutoff 재검토 backlog 후보

- 현재 cutoff ≥34 매우 강 = random 33% 통과
- 만약 random 5%만 통과하는 cutoff (예: ≥50?)를 매우 강 정의로 바꾸면 1티어 5명 중 세형(52)만 매우 강이 됨 → 너무 보수적
- 현행 cutoff 유지하되 **라벨 위상을 정직하게 (특별함 ✗, 통계적 상위 1/3)** 표현하는 게 합리적
- 외부 100명 단계에서 random 5%·10% cutoff 등 다층 라벨 도입 검토

## 4. 결정 사항

### 4-1. 확정 (이 검증 기반)

1. **시스템 v7 시그너 구조 유지** — 신호 실재 확정.
2. **표현 약화 작업(★★★ ①) 톤 = "중간"** — 강한 단언 ✗, 그러나 "신호 ✗" 톤도 ✗. 시그너 hit 갯수·점수 위주 객관 표현.
3. **Cohort confound 추가 면책 문구 ✗** — 이 검증으로 무력화됨. `CALIBRATION_BIRTH_MONTH.md`의 명리 본질 면책 문구만 유지.

### 4-2. 백로그 (이후 단계)

- N=11 LOOCV (★★★ ③) — 일반화 갭 측정
- youthLuck 16-22 ×1.5 또는 ×2 실험 (★★ ⑤) — LOOCV 후 비교
- Cutoff 다층 라벨 (★) — 외부 100명 단계
- random 매우 강 통과 sample의 시그너 패턴 분석 — 어떤 시그너 조합이 "noise" 인지
