# eduluck A-0 v3 — 생각을 문서로

> 정책 v16 기준. 1차 독자: Eugene (외주 기획자). 산출물 컨펌·A-1 진입 결정용.

---

## 1. 핵심 가설 한 문장

**학생(초·중·고) 자녀를 둔 30~45세 어머니가, 학년·진로 결정 시점에, 자녀 사주만 입력해 무료 간이 학운 진단을 받은 뒤, 본인 사주를 추가하고 정밀 분석에 결제할 것이다.**

## 2. 왜 지금인가

1. AI 한국어 사주 해석 품질이 2024~2025 사이 임계치 돌파. 작년 이전엔 어색했음.
2. 사교육비 사상 최대, 학부모의 진로·적성 데이터 의사결정 수요 ↑.
3. 시장 빈자리: 사주 앱(점신·포스텔러)은 단발 운세 / 입시 컨설팅(진학사·메가스터디)은 비쌈 + saju 0 → 사이 자리.

## 3. 누가 쓰는가

- 30~45세 **어머니** (수도권·광역시), **학생(초·중·고) 자녀** 1~2명
- 사교육비 월 50~150만원 지출, 자녀 진로·강점·취약점 고민 활발
- 현재 대안: 맘카페·학원 상담·운세 앱·친정엄마. **saju 친화도 경험적으로 높음**
- 모바일 절대적, 인스타·맘카페 유입
- **학년대별 결정 시점:**
  - 초등 = 학원 선택, 진로·적성 탐색
  - 중등 = 진로 분기(특목고·일반고·영재), 과목 우선순위
  - 고등 = 입시 정밀 전략, 과 선택

## 4. 러프 유즈케이스 메인 라인

1. 인스타 광고·맘카페에서 발견 → 모바일 진입
2. 자녀 사주(생년월일시)만 입력 → 무료 간이 학운 진단 결과 읽음
3. 결과 끝에 "본인 사주 추가 → 정밀 분석" 안내
4. 어머니 본인 사주 입력 → 결제 → 정밀 진단 결과 표시
5. (v2) 매년 세운 갱신 자동 알림 → 재진단, 자녀 학년 따라 톤·내용 자동 진화

## 5. MVP 경계

| 항목 | 이번 버전 고정 | 배제 | 예시 |
|---|---|---|---|
| 제품 1개 | **React Native(Expo) 기반** saju 종합 학운 진단 (자녀 + 어머니 사주) | 입시 컨설팅·적성검사·종합 운세·재물운·아버지 사주 필수·부모 학력 필수 | 학년대별 갱신되는 학운 진단 (1:1 입시 상담·연애운·종합 사주풀이 제외) |
| 타겟 세그먼트 1개 | **학생(초·중·고) 자녀** 둔 30~45세 어머니 (수도권·광역시) | 아버지 결제자, **자녀 직접 사용**(중·고생 본인 사용은 v2), 미혼·지방 | 학생 자녀 1~2명, 사교육비 월 50만원+, 인스타·맘카페 활동 |
| 목표 행동 1개 | 무료 간이 진단 → 정밀 진단 **첫 결제** | 회원가입만·웨이팅리스트·단순 재방문 | 어머니 사주 입력 + 정밀 진단 결제 완료 |

**왜 좁히는가:** 학생 자녀 둔 어머니 = 구매력 · 진로 관심도 · saju 친화도 분포 양호. 학년대별 결정 시점이 모두 다르나(초=학원/적성, 중=진로 분기, 고=입시 전략), **공통적으로 학운 진단 가치 유효**. 학년대별 콘텐츠 톤 분기(초저·초고·중·고)로 한 제품에서 모두 커버 가능. 자녀 직접 사용 화면은 톤·UX 별도 설계 필요 → v2.

**부모 학교/과·아버지 사주는 완전 옵션:** 시스템에 입력 칸은 있지만 "넣으면 정확도 더" 정도 포지셔닝. 메인 흐름·핵심 가설에는 포함하지 않음.

## 6. Kill / Go / Hold 판정

**Go** — A-1 진입.

근거 3줄:
1. AI saju 해석 품질 임계 + 사교육 시장 수요 검증 = timing 양호
2. 무료→유료 funnel이 saju 정확도 향상(어머니 사주 추가)과 **자연 정렬** — conversion 논리 인위적이지 않음
3. 매년 세운 갱신 = retention 메커니즘이 saju 도메인 자체에서 나옴 (명리 이론 기반, v2 확장)

## Claude의 적대적 압박 — Kill할 이유 세 가지

1. **자녀 사주만 무료 진단의 mom test 미검증** — funnel 진입 첫 관문이 "자녀 사주만 입력한 간이 결과"인데, 이게 "와, 정확하네" 감탄 수준일지 검증 안 됨. baseline 단독 정확도가 약하면 그 다음 모든 단계가 무너짐. AI saju 해석 품질이 임계 넘었다는 §2 전제가 진짜인지 v1 첫 화면에서 사용자 5명에게 무조건 시연 검증 필요.

2. **"+25% 정확도" 결제 trigger의 추상성** — 학부모는 % 클레임으로 결제 안 함. "내 아이의 학년 강점·취약점 구체 정보 + 시기별 액션 가이드" 같은 실용 가치가 결제 trigger임. v1 결제 직전 화면에서 "추가 입력 시 받을 구체 가치"가 충분히 구체로 안 보이면 conversion 망함.

3. **매년 갱신 가치 미검증 (v2 확장 이슈)** — 학부모가 1년 만에 "또 결제할 이유"를 느낄지 불확실. 첫 정밀 진단이 충분히 정확하면 오히려 재진단 욕구 약화 가능. 매년 세운 갱신은 명리 이론이지 행동 검증 없음. 구독 유지율 가설이 가장 약한 고리. v2 확장 시 "매년 무엇이 새로 보이는가" 콘텐츠 차별화 설계 필수.

## 후속 메모 (A-1 입력용)

- **기술 스택**: **React Native (Expo Router) 무조건.** 동일 코드베이스 → Vercel(web) + EAS Build(iOS·Android). marketing 페이지(랜딩·블로그)는 별도 Next.js로 분리 검토.
- **부모 사주 입력 정책**: 자녀 = 필수 / 어머니 = 정밀 진단 필수 / 아버지 = 완전 옵션 / 부모 학교·과 = 완전 옵션.
- **학년대별 콘텐츠 톤 (v3 신설)**:
  - 초저(1~3) = 학습 습관·강점 식별
  - 초고(4~6) = 학원·진로 방향
  - 중(1~3) = 과목 우선순위·특목고/일반고 결정
  - 고(1~3) = 입시 전략·과 선택
  - A-1 prompt 설계에 분기 반영.
- **포지셔닝**: saju 중심으로 시작. 입시 컨설팅 요소는 학년 올라가며 layer 추가.
- **사용자 확장 로드맵 (v3 갱신)**: v1 학생(초·중·고) 어머니 사용 → v2 자녀(중·고) 직접 사용 화면 + 부모 추가 옵션 확장 + PDF·대시보드·매년 갱신.
- **A-1 핵심 의제 (Kill 3번 약한 고리 대응, v2 확장)**: "매년 갱신 시 학부모에게 보이는 새 가치가 무엇인가" — 세운 변화만으로는 약함. 학년 진급·발달 단계·누적 데이터 trend가 같이 갱신되는 콘텐츠 설계 필요.
