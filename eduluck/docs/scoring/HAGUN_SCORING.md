## 0. 면책 — 본 문서가 주장하지 않는 것

이 시스템은 **명리학적 학자형 본질의 정량 추정 + 한국 입시 휴리스틱 매핑**이다. **입시 결과 예측 모델이 아니다.**

| 본 시스템이 주장하는 것 | 본 시스템이 주장하지 않는 것 |
|---|---|
| 명리 합의 기준 학자형 사주 시그너의 강도 추정 | "이 아이는 OO대 간다"는 예측 |
| 청소년기(6~22세) 대운의 학업 친화성 정성 평가 | 사주가 입시 결과의 주요 결정 변수라는 주장 |
| 9명 calibration sample 기준 in-sample 정합 | out-of-sample 일반화 능력 (미검증) |

**실제 입시 결과**는 부모 SES·강남 거주·고등학교·사교육 시간·인지능력·학습 습관 등 검증된 변수들의 설명력이 사주 시그너보다 훨씬 크다 (KEDI·KDI·OECD PISA 2022 합의).

**Self-fulfilling prophecy 주의**: 사주는 "가능성의 지도"이지 "결정된 미래"가 아니다. 어머니가 결과를 보고 자녀 진로를 미리 닫는 도구로 쓰면 안 된다.

**Month-effect confound 미해결**: 사주의 월지·연주는 출생일의 결정론적 함수라 한국 학교 학년 cutoff·월령 효과 (배호중 2020)와 분리 불가. N=9 sample에서 1티어 5명 중 여름(6-8) 출생 0명, 비1티어 4명 중 여름 출생 3명 — 사주 시그너가 학교 적응 우월성을 명리 용어로 재라벨링한 것일 가능성을 배제할 수 없다. 자세한 분석: [CALIBRATION_BIRTH_MONTH.md](../run/CALIBRATION_BIRTH_MONTH.md).

**학파 메타 라벨**: 본 시스템은 **자평명리 격국론** (자평진전·적천수) + **연해자평·삼명통회 신살·귀인 학파**를 한국 입시 휴리스틱 목적으로 의식적 절충한 모델이다. 단일 학파 일관성보다 한국 입시 sample 정합을 우선했다.

**Counterfactual 결과 (2026-05-23, N=1000 random 사주 vs 1티어 5명)**: 무작위 사주의 약 **33%가 cutoff ≥34 "매우 강" 영역에 들어온다**. 즉 "매우 강"은 "특별한 자리"가 아니라 **통계적 상위 1/3** 위상이다. 1티어 5명 평균(40.6)은 매우 강 영역 내 중상위에 위치하며, "확실한 1티어" 단언은 정직하지 않다. 자세한 분석: [CALIBRATION_COUNTERFACTUAL.md](../run/CALIBRATION_COUNTERFACTUAL.md).

## 1. 왜 학운 티어인가

### 1-1. 목적

"이 아이의 사주 기준 도달 가능한 한국 입시 티어 범위는 어디까지인가"를 한 축으로 평가한다. 어머니가 "SKY가 보이는가 / 인서울 / 지방 거점 / 비대학 트랙"을 직관적으로 받을 수 있어야 함.

방향성과 분리한 이유: **"어디로(방향) × 얼마나(티어)"** 는 다른 축이다. 학자형 강 + 학업 약은 어색하므로 양쪽 모두 학자형 본질을 핵심 시그너로 사용하지만, 티어 축은 입시 통설 (관인상생·격국·학자귀인·청소년 대운)을, 방향 축은 직업 분기 (정인→학자 / 정재→경영 / 화개살→예술 등)를 본다.

### 1-2. 단일 점수 누적의 한계 → 4-Layer

v5까지 22개 시그너 단순 합산 방식의 문제:

- **1티어 sample 분리 부족** — Eugene·정환·세형·이윤수·류상수 5명이 +10~+11에 뭉침. 통설 기준 cutoff(≥+13)으로 잡으면 무너짐.
- **관인상생 단독 변별력 −7%** — 1티어 3/5, 4~6티어 2/3에서 동시 발동. 단독 시그너로는 변별 ✗.
- **명리 표준과 거리** — KCI 메타 분석상 명리 정량 가중치 합의는 없음. 표준은 **"본질-역량-시기"** 3계층 사고.

v6에서 3-Layer (Boolean + 명식 + 운 + 페널티)로 재구조화, v7에서 신살·귀인 카테고리(Layer 2)를 분리해 4-Layer + 14 시그너로 확장.

### 1-3. 4-Layer 구조

```
Layer 0  Boolean 학자형 본질            (라벨 — 점수 산입 ✗)
Layer 1  명식 본질                       (0 ~ 60+)
Layer 2  신살·귀인                       (0 ~ 20)   ← v7 신설
Layer 3  운 (청소년 대운 + 관성)         (0 ~ 20)
Layer 4  페널티 (신약·재극인·학자형부재)  (−35 ~ 0)

total = max(0, min(100, Layer1 + Layer2 + Layer3 + Layer4))
```

## 2. Layer 0 — Boolean 학자형 본질

점수에 직접 산입되지 않고 LLM 풀이 톤·UI 라벨에 사용되는 boolean 라벨.

```typescript
isScholar = (관인상생 OR 학자격국narrow OR 양인+제왕+다귀인)
            AND 학자귀인 ≥ 1
```

**왜 이 식**: 8명 calibration 변별력 매트릭스 검증에서 **precision 100% + recall 100%** (Rule 5 — `8-sample-signer-audit.ts`). 다른 단일·콤보 조합은 모두 정밀도·재현율 하나 이상 떨어짐.

학자귀인 = 문창귀인·학당귀인·문곡귀인 (천을귀인은 메타 길성이라 [student-traits.ts](../../lib/manse/student-traits.ts)에서 별도 활용).

## 3. Layer 1 — 명식 본질 (0 ~ 60+)

명리 합의에서 학자형 본질을 강하게 보는 7개 시그너. cap 없음 (자연 cap ≈ 60+). "타고난"은 명리 통설 라벨이지 절대 단언이 아님 — Counterfactual 기준 random 사주의 1/3도 이 영역에 들어옴.

| # | 시그너 | weight | 명리 근거 |
|---|---|---|---|
| 1-1 | **관인상생 + 학자귀인 ≥ 1 콤보** | +15 | 단독 관인상생 변별력 −7%, 콤보일 때만 의미 (8명 audit) |
| 1-2 | **학자형 격국 narrow** (정관·정인·편인·식신·건록격) | +12 | 편관격 제외 — 의약·법조는 [medical-score.ts](../../lib/manse/medical-score.ts) 별도 모듈 |
| 1-3 | **학자귀인 ≥ 3 / 2 / 1** | +10 / +7 / +4 | 8명 audit 단일 변별력 +67% — 최강 단일 |
| 1-4 | **인성 ≥ 2 / 1** | +8 / +4 | saju-master "학문 기본" |
| 1-5 | **자립 학자형 콤보** (정인·편인·정관격 + 일지 건록·제왕 + 비겁 ≥ 2) | +12 | 자평진전 "正印格喜身旺" — Eugene POSTECH 패턴 |
| 1-6 | **학자형 양인** (양인격 + 월지 강 + 학자귀인 ≥ 2) | +5 | 이윤수 (서울대 전자) 패턴 — 양인+천우신조 |
| 1-7 | **일주 통근** (일지가 비겁) | +5 | 적천수 "통근투출" — 일간 본거지 |

### 펙터 선정 이유

- **1-1 콤보 우선**: 관인상생만 발동하면 1티어와 4~6티어 모두 잡혀 변별 ✗. 학자귀인 ≥ 1 동시 조건으로 잠금.
- **1-2 narrow (편관격 제외)**: 편관격은 의·법·외과로 분기되므로 학운 일반 티어와 별도 트랙. 의약 sample(세형·두흥)은 medical-score에서 가중.
- **1-5 자립 학자형**: Eugene 같은 정인격 + 일지 건록 + 비겁 강 패턴이 v6 이전엔 "신왕 페널티"를 받음(자기 격국이 자기를 누르는 모순). 자평진전 "正印格喜身旺" 합의로 +12 콤보 신설.
- **1-7 일주 통근**: 일간이 일지에 뿌리 내림 → 본인 의지·체력 강 → 학업 지속력. 자립 학자형과 짝지어 이공계 1티어 sample을 명확히 분리.

## 4. Layer 2 — 신살·귀인 (0 ~ 20)

v7 신설 카테고리. Agent 명리 리서치 (연해자평·삼명통회) 권장 반영.

| # | 시그너 | weight | 명리 근거 |
|---|---|---|---|
| 2-1 | **천을귀인 ≥ 2 / 1** | +6 / +4 | 연해자평 "最上貴" — 메타 길성 |
| 2-2 | **천덕 + 월덕 동시** | +5 | 삼명통회 "천우신조 팔자" (단독 천덕·월덕은 +2) |
| 2-3 | **삼귀구비** (천을 + 천덕 + 월덕) | +5 | 삼명통회 "天乙·天德·月德 三貴同臨 名曰天地人三才俱備" — 중첩 보너스 |
| 2-4 | **삼기귀인** (천상 갑무경 / 지하 을병정 / 인중 임계신) | +5 | 삼명통회 "三奇爲貴" — 비범한 두뇌. 4기둥 모두 있어야 발동 (시간 모름 시 자동 ✗) |

### 펙터 선정 이유

이윤수(서울대 전자) sample이 v5 점수 3점 머문 이유 진단: 양인격이라 1-2 narrow에서 제외 + 인성 약. 그러나 명식에 양인 + 학당·문창 + 천덕·월덕 모두 있는 "천우신조 양인" 패턴. v6까지 신살·귀인을 명식 본질에 섞었더니 noise. v7에서 별도 Layer로 분리 + 중첩 보너스 (삼귀구비)로 보강 → 이윤수 +12 → 총점 34 도달.

## 5. Layer 3 — 운 (0 ~ 20)

청소년기 (6~22세) 대운 흐름. 명리 합의에서 사주 원국보다 대운이 입시 결과를 결정 (플러스운세력·sajustudy 대운·세운 표준).

| # | 시그너 | weight | 조건 |
|---|---|---|---|
| 3-1 | **청소년 대운 강 / 보조 / 중립** | +15 / +8 / +4 | youthLuck ≥ 3 / ≥ 1 / 0 |
| 3-2 | **관성 단독 ≥ 2 / 1** | +5 / +3 | 명식 관성 개수 (시험 친화) |

### youthLuck 계산

```
SCHOLAR_LUCK = 정인·편인·정관·편관
HEADWIND_LUCK = 정재·편재

youthLuck = Σ (대운 천간 십성 + 지지 십성) 가산
            대운 중 age 6~22 범위만 카운트
            학자형 +1 / 역풍 −1 / 그외 0
```

### 펙터 선정 이유

- **3-1만 가산, 3-2는 보조**: 청소년기 대운이 학업 시기와 직결되므로 절대 가중치. 명식 관성은 시험·체계 친화이긴 하나 학자형 본질(Layer 1) 시그너와 겹치므로 weight 낮춤.
- **youthLuck 0도 +4 부여**: 사주가 약해도 청소년기에 역풍 ✗이면 환경·노력으로 보강 가능. "0점 sample 14.88%"를 만들지 않기 위한 기본 보장.

## 6. Layer 4 — 페널티 (−35 ~ 0)

| # | 시그너 | weight | 명리 근거 |
|---|---|---|---|
| 4-1 | **신약** (sinwang ≤ −3) | −15 (정인·편인격 예외 **−5**) | 자평진전 "정인격 신약 페널티 완화" — 정인격이 신약하면 인성으로 통근 보완 |
| 4-2 | **재극인** (재성 ≥ 3 + 재성 ≥ 2×(인성+1) + 학자귀인 ≤ 1) | −10 | 다시 배우는 사주명리 — 재성 과다가 인성 극 → 학업 견제 |
| 4-3 | **학자형 부재 콤보** (학자귀인 0 + 학자형 격국 ✗ + 일지 약) | −10 | 3조건 동시 — "학자 자리 자체가 없음" |

### sinwang 계산

```
sinwang = (비겁 + 인성) − (식상 + 재성 + 관성/2)
        + 월지 12운성 (건록·제왕 +2 / 쇠·병·사·묘·절·태 −1)
        + 일지 12운성 (동일)
```

### 펙터 선정 이유

- **4-1 정인격 예외**: v6 이전엔 신약 일률 −15. 정인격 + 신약 sample(잠재 학자형)을 너무 깎아냄. 자평진전 합의로 정인격·편인격은 −5만 적용.
- **4-2 재극인 3조건**: 재성 단순 카운트로는 정재격·편재격까지 깎임. "재성 ≥ 3 AND 재성이 인성의 2배 초과 AND 학자귀인 거의 없음" 3조건 동시일 때만 발동.
- **4-3 부재 콤보**: 사주가 진짜 학자 본질에서 멀 때만 발동. 한 조건이라도 있으면 ✗. 와이프(울산대) 같은 sample이 여기에 걸림.

## 7. 점수 → 등급 → 베이스 티어

```typescript
total = max(0, min(100, Layer1 + Layer2 + Layer3 + Layer4))
```

| 점수 범위 | 등급 | 베이스 티어 | 분포 인구비 |
|---|---|---|---|
| **≥ 34** | 매우 강 | 1 ~ 2 티어 | 상위 ~30% |
| **22 ~ 33** | 강 | 2 ~ 3 티어 | 상위 ~50% |
| **14 ~ 21** | 중상 | 3 ~ 4 티어 | 상위 ~70% |
| **8 ~ 13** | 중 | 4 ~ 5 티어 | 상위 ~80% |
| **4 ~ 7** | 중하 | 5 ~ 6 티어 | 상위 ~85% |
| **1 ~ 3** | 약상 | 6 ~ 7 티어 | — |
| **0** | 약중 이하 | 7~8 티어 또는 비학문 트랙 (예술·실무·운동 등) | ~15% (사주 신호가 학자형보다 다른 영역에 강한 구간) |

### Cutoff 선정 근거

분포 시뮬레이션 N=56,988 (2008~2020 × 365일 × 12 시간 슬롯 × 2 성별):

- min=0, max=91, mean=25.33, stddev=17.01
- p50=25, p75=37, p90=49, p95=55, p99=64, p99.9=73

**≥34 매우 강 = 상위 ~30%**: 5명 1티어 sample 모두 ≥34 도달 (Eugene 40·정환 34·세형 41·이윤수 34·류상수 46). 사용자 요구("분포 보수적 + 1티어 sample 1~2티어 매핑") 절충 지점.

## 8. 티어별 대표 학교 (한국 입시 체감 난이도 — 참고 예시)

> **단언 ✗ — 참고용 매핑**. 본 표는 사용자가 "1티어"·"5티어" 등 추상 라벨의 체감을 잡기 위한 한국 입시 통설 매핑이지, "이 사주는 OO대 간다"는 예측 ✗. 같은 티어 안의 학교 간 우열·전공 차이는 본 시스템이 단언하지 않는다.

| 티어 | 대표 학교 (체감 예시) |
|---|---|
| 1 | 서울대 · POSTECH · KAIST · 의예 / 연·고대 상위과 |
| 2 | 연·고대 · 서강 · 성균관 · 한양 (의예·법 포함) |
| 3 | 서강 · 성균관 · 한양 · 중앙 · 경희 |
| 4 | 중앙 · 경희 · 한국외 · 시립 · 이대 |
| 5 | 건국 · 동국 · 홍익 · 경북대 · 부산대 |
| 6 | 인하 · 아주 · 국민 · 숙명 · 세종 · 울산대 |

## 10. 부모 환경 조정 (`parentAdjust`)

부모 사주 입력 시 ±2 가산 한도 내에서 베이스 티어 조정 ([calcParentAdjust](../../lib/prompts/hagun-tier.ts#L355)).

| 조건 | 가감 |
|---|---|
| 어머니 일간 → 자녀 정인·편인 작용 | +1 (학문 받쳐줌) |
| 어머니 일간 → 자녀 정재·편재 작용 | −1 (인성 극, 학업 견제) |
| 아빠 일간 → 자녀 정인·편관 작용 | +1 (성장 자극, 가중치 절반) |
| 아빠 일간 → 자녀 비견·겁재·정재·편재 | 0 (자원 분산 가능, 가중치 절반) |
| **한도** | **±2** |

부모 미입력(현재 기본)이면 `parentAdjust = 0` → 베이스 티어 = 최종 티어.

부모 학력 가중치는 Phase H에서 mom test 단계 UX 단순화 목적으로 제거 ([university-tier.ts](../../lib/manse/university-tier.ts)·resolveParentTier 함수는 코드 유지 — 향후 재도입 옵션).

## 11. 최종 티어 산출 (`calculateFinalTier`)

```
1. hagunScore = computeHagun(childManse).total
2. gradeInfo = scoreToGrade(hagunScore)
3. parentAdj = calcParentAdjust({childManse, motherManse, fatherManse, ...})
4. [lo, hi] = baseTierRange − parentAdj.total (clamp ≥1)
   단, 베이스가 전문대(11)·비대학(12)이면 고정 (반전 ✗)
5. conf = calcConfidence(hagunScore, [lo, hi])
6. finalTierRange = [lo, hi]
   primaryTier = lo (낮은 숫자 = 위)
   safetyTier = hi (또는 lo+1 if 단일)
```

산출물 (`FinalTierResult`)이 LLM §13·UI HagunCoreCard에 그대로 주입.
