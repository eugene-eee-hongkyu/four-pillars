## 1. 문제 정의

현재 `scoreHagun` (옵션 A, 22개 시그너 합산)의 한계:

- **1티어 sample 분리 부족**: Eugene·정환·세형·이윤수·류상수 (실제 1티어 5명) 중 다수가 +10~+11에 머묾. cutoff을 입시 통설(≥+13 = 상위 ~5%)로 잡으면 무너짐
- **관인상생 단독 변별력 ✗**: 1티어 3/5, 4~6티어 2/3 발동 (변별력 −7%)
- **단일 점수 누적이 명리 표준과 거리**: KCI 메타분석상 명리 정량 가중치 합의 부재. 명리 표준은 "본질-역량-시기" 계층적 사고

### 평가 방식 권장

- ❌ A. 다축 평가 — 명리 표준 텍스트에 명시적 다축 점수표 없음
- ✅ **B. 계층적 평가** — 명리 강사 실제 프레임 ("1순위 명식 → 2순위 대운")
- ⚠ C. Boolean Rule — 그라데이션 표현 ✗, 라벨에만 사용
- ✅ **D. 격국 진위 가중치** — 진격 ×1, 가격 ×0.5 (전통)
- ✅ **E. 명·운 분리** — 70점 본질 / 30점 운

**채택: B + D + E 하이브리드**

### Boolean Rule 평가

| Rule | precision | recall |
| --- | --- | --- |
| Rule 1: 관인상생 only | 60% | 60% |
| Rule 2: 학자귀인 ≥1 | 83% | 100% |

## 6. 권장 — 3-Layer 평가 (옵션 C)

### Layer 0: Boolean 라벨

```
학자형 본질 = (관인상생 OR 학자형 격국 narrow OR 양인+제왕+다귀인)
              AND 학자귀인 ≥ 1
```

→ **TRUE** = "학자형 본질 있음 (1~2티어 가능)"
→ **FALSE** = "학자형 본질 약 (3티어 이하)"

우리 sample 검증: 8명 100% 정합

### Layer 1: 명식 본질 점수 (70점)

| 시그너 | 가중치 | 비고 |
| --- | --- | --- |
| 관인상생 + 학자귀인≥1 콤보 | 18 | 단독 ✗ |
| 학자형 격국 narrow | 15 | 편관격 제외 (의약 트랙 별도) |
| 학자귀인 (문창·학당·문곡) | 12 | ≥3 full / 2 = 8 / 1 = 5 / 형충공망 ×0.5 |
| 인성 (정인·편인) | 10 | ≥2 full / 1 = 5 |
| 일간 강도 균형 | 8 | 신왕 적정 = full / 신약·태강 = 0 |
| 양인+제왕+다귀인 (학자형 양인) | 7 | 특수 학자형 (이윤수) |
| **합** | **70** | — |

### Layer 2: 운 점수 (30점)

| 시그너 | 가중치 | 비고 |
| --- | --- | --- |

| 정관·편관 단독 (관성≥1) | 10 | 관인상생 외 가산 |
| **합** | **30** | — |

### Layer 3: 페널티

| 시그너 | 가중치 | 비고 |

## 7. 제거 후보 시그너 (현재 22개 → 9개)

**제거**:
- ❌ 학자형 납음 (Agent 미언급)
- ❌ 추진력형 패턴 (1티어 0/5 발동)
- ❌ 학자 트라이앵글 콤보 → Layer 0 Boolean로 흡수
- ❌ 관인상생 유연화 → 단순화
- ❌ 자립 학자형 패턴 → Layer 1에 흡수
- ❌ 4귀인 세분화 (gui1, gui2, gui3) → 학자귀인 합산
- ❌ 비학문 강세 → 신약과 중복
- ❌ 청소년 식상 대운 (추진력형 한정) → 너무 좁음

**유지 (9개)**:
1. 관인상생 + 학자귀인≥1 콤보
2. 학자형 격국 narrow
3. 학자귀인 (문창·학당·문곡)
4. 인성 (정인·편인)
5. 일간 강도 균형
6. 청소년기 대운
7. 관성 단독
8. 양인+제왕+다귀인 (학자형 양인)
9. 신약 페널티 + 재극인 + 학자형 부재 콤보
