# 사주 학운 30티어 시스템 v2 — 최종안

> 본 문서는 2025 정시 배치표(송원학원·비상교육·베텔기우스) 기준으로 한국 사회의 학업 분포를 30단계로 매핑한 휴리스틱 시스템이다. 사주 명리학 기반 학운 점수를 실제 사용자가 이해할 수 있는 대학·진로 군으로 치환하기 위한 내부 기준 문서.

## 0. 변경 이력

- **v1**: 초안 30티어 설계 (의약·예체능·특수목적·교대 별도 트랙으로 제외)
- **v2 (현재)**: 모든 트랙을 30티어 안에 통합. 컬럼 분리(일반학과 / 별도 트랙). 발현 조건 매트릭스 추가. 워딩 가이드 추가.

## 2. 핵심 설계 원칙

1. **30티어는 사회 분포 매핑이다.** 1-1(1.67%)~10-3(100%)는 한국 18세 인구 약 47만 명의 누적 백분위.
2. **티어는 "학업 에너지 총량"을 의미한다.** "발현 방향"이 아니다. 같은 1-1이라도 사주의 다른 시그너로 의대/유학/카이스트가 갈라진다.
3. **모든 트랙을 30티어 안에 포함시킨다.** 의약·예체능·특수목적·교대·전문대·비대학을 모두 매핑.
4. **컬럼은 2개로 고정한다.** "일반 대학군"과 "별도 트랙"을 섞지 않는다.
5. **하위 티어는 비대학 진로로 정직하게 채운다.** 학운이 약한 것은 사주에서 다른 운(재성·식상)이 강하다는 신호이지, 인생이 약한 것이 아니다.

## 4. 발현 조건 매트릭스 (분기 로직)

같은 학운 티어라도 다른 사주 시그너에 따라 트랙이 갈린다. 이 매트릭스가 30티어와 곱해져 최종 진로 텍스트가 출력된다.

### 4.1 학운 1-1 ~ 1-3 (상위 5%) 분기

| 학운 | 트리거 시그너 | 발현 트랙 |
|---|---|---|
| 1-1~1-3 | **외국운(역마)** + 환경(부모 글로벌·언어환경) | 하버드·MIT·Ivy 학부 |
| 1-1~1-3 | **현침살 / 인성 안정** / 부모 의료 환경 | 의예·치의예·한의예 |
| 1-1~1-3 | **격국 짜임 + 식상** / 연구 기질 | KAIST·POSTECH·UNIST |
| 1-1~1-3 | **관성 강** / 규율 | 사관학교 (1-2~1-3급) |
| 1-1~1-3 | 위 조건 모두 약함 | 서울대 일반 / 연·고대 일반 |

### 4.2 학운 2-1 ~ 2-3 (5~12%) 분기

| 학운 | 트리거 시그너 | 발현 트랙 |
|---|---|---|
| 2-1~2-3 | **외국운 + 언어 적성** | 한국외대 / 유학 Top 50~100 |
| 2-1~2-3 | **예술 시그너** (식상 + 화기) | 한예종 / 홍익 미대 / 서울대 미대 |
| 2-1~2-3 | **관성 + 인성** (교사 기질) | 서울·경인교대 |
| 2-1~2-3 | **관성 강** + 규율 + 신체 | 사관학교 일반 |
| 2-1~2-3 | 위 조건 모두 약함 | 서·성·한 / 중경외시 / 이건동홍 일반 |

### 4.3 학운 3-1 ~ 6-3 (12~56%) 분기

이 구간은 **[티어 대학군] + [방향성 학과 방향]** 형식으로 출력:

```
출력 형식 = [티어 대학군] + [방향성에 따른 학과 방향]

예시:
- 학운 4-1 + 방향성 "공학/기술" → "지방거점국립대 또는 한양(ERICA)의 공학·IT 계열"
- 학운 4-1 + 방향성 "경영/상경" → "지방거점국립대 또는 가천대의 경영·경제 계열"
- 학운 5-2 + 방향성 "보건/의료" → "지방 사립의 간호·물리치료·임상병리 계열"
```

## 5. 워딩 가이드 (사용자 출력 문구)

### 원칙

- **사실(티어·누적%)은 그대로** 출력
- **해석(명리학 프레이밍)만** 긍정·중립 톤으로
- 절대 금지: "8티어도 좋은 자리" (사실 왜곡), "당신은 명문대 가는 사주" (확정적 단정)
- 권장: "X 구간의 학업 흐름 / Y 방향에서 성취 발현 가능"

### Tier 1 (상위 5%)
> "학운이 최상위 흐름입니다. 일반학과 기준 서울대~연·고대 인기학과, 별도 트랙으로는 의예·과기원·해외 명문 진학이 가능한 강한 학업 에너지입니다. 방향성에 따라 발현 분야가 갈립니다."

### Tier 2 (5~12%)
> "학운이 매우 강한 흐름입니다. 서·성·한 ~ 중경외시 라인 또는 의약·치한약 / 사관·경찰대 / 교대 등 다양한 트랙이 열려 있습니다."

### Tier 3 (12~22%)
> "학운이 안정적으로 강합니다. 건국·동국·홍익~국숭세단 라인 또는 지거국 상위, 인하·아주 라인이 가능한 흐름입니다."

### Tier 4 (22~32%)
> "학운이 평균보다 강합니다. 지방거점국립대 또는 수도권 중위 사립(가천·명지·상명) 라인을 안정적으로 노려볼 수 있습니다."

### Tier 5 (32~44%)
> "학운이 보통입니다. 지방 사립 강자(영남·계명·한림·순천향) 또는 지방거점국립대 일반학과 라인입니다."

### Tier 6 (44~56%)
> "학운이 보통 이하입니다. 지방 4년제 사립 일반 또는 수도권 외곽 사립 라인이며, 방향성을 명확히 잡으면 4년제 진학 가능 구간입니다."

### Tier 7 (56~68%)
> "학운으로 승부하기보다 실무·기술 트랙에서 빛나는 사주 흐름입니다. 전문대 명문 학과(보건·IT·디자인 등) 또는 4년제 사립 하위 학과 진학 후 빠른 실무 진입이 적합합니다."

### Tier 8 (68~80%)
> "제도권 학업이 짧은 대신 실전 감각이 강한 사주입니다. 전문대 기술 특화 학과 또는 자격증 기반 조기 취업이 타고난 식상·재성을 발현시키는 길입니다."

### Tier 9 (80~90%)
> "학업으로 시간을 들이기보다 일찍 사회에 진입할 때 성취가 큽니다. 사이버대·학점은행제·직업전문학교를 병행하거나, 가업·자격증 기반 진로가 적합합니다."

### Tier 10 (90~100%)
> "제도권 교육의 틀을 벗어나 실전형·현장형 경로에서 빛나는 사주입니다. 빠른 사회 진출, 가업 승계, 기술 자격증, 군 직업 트랙 등이 타고난 재물·식상 운을 가장 크게 발현시킵니다. 단, 20~30대 대운 변화에 따라 만학 가능성이 열려 있을 수 있으니 별도 확인 권장."

## 6. 제품 적용 시 주의사항

1. **30티어는 "강도"만 의미**한다. "방향"은 별도 시그너로 결정.
2. **별도 트랙 노출 조건**:
   - 의약 트랙 → 학운 1-1~2-1 + 현침살 / 의료 환경
   - 해외 트랙 → 학운 1-1~2-3 + 외국운 / 언어환경 / 부모 환경
   - 예체능 트랙 → 방향성 점수 우선, 학운은 보조
   - 사관·경찰 → 학운 + 관성 + 신체 적성
   - 교대 → 학운 + 인성 + 관성
3. **하위 티어 출력은 정직하게**. 과도한 미화 금지. 명리학적 의미 부여로 충분.
4. **변동성 라벨**(교대, 분교, 사관) 적용 시 "±1티어 가능" 표시.
5. **대운 변화는 별도 레이어** (현재 v2에 미포함). 다음 작업으로 진행.
