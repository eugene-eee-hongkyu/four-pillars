## 1. 학운 종합 점수 (티어)

### 1-1. 점수 범위

| 구분 | 점수 | 비고 |
|---|---|---|
| 이론상 최대 | **+18** | 모든 시그너 매치 (학자형 격국 + 추진력형 동시 ✗라 실질 +16) |
| 이론상 최저 | **-9** | 모든 페널티 매치 |
| 실제 분포 범위 | **약 -7 ~ +13** | 일반 사주 정상 분포 |

### 1-6. 부모 환경 조정 (`parentAdjust`)

부모 사주 입력 시 ±2 가산 한도 내에서 베이스 티어 조정.

| 조건 | 가감 |
|---|---|
| 어머니 일간 → 자녀 정인·편인 작용 | +1 (학문 받쳐줌) |
| 어머니 일간 → 자녀 정재·편재 작용 | -1 (인성 극, 학업 견제) |
| 아빠 일간 → 자녀 정인·편관 작용 | +1 (성장 자극, 절반 가중치) |
| 아빠 일간 → 자녀 비견·겁재·정재·편재 | 0 (자원 분산 가능, 절반 가중치) |
| **한도** | **±2** |

부모 미입력(현재 기본)이면 parentAdjust = 0 → 베이스 티어 = 최종 티어.

### 1-7. Confidence 표현 — 같은 등급 안에서도 점수 강도

같은 "매우 강" 사주라도 점수에 따라 LLM 풀이 톤 미세 조정:

| 점수 | Confidence 라벨 |
|---|---|
| +12 | "1티어 가능 + 2티어 안정" |
| +11 | "1~2티어 안정" |
| +10 | "2티어 가능 + 1티어 도전" |

§13 학교 권유에서 "안정·가능·도전" 3구간 톤이 점수에 따라 미세 조정됨.

## 2. 학운 10가지 특성 점수 (UI 카드)

§0 직후 노출되는 시각 hook. 각 항목 0~100 점수 + 상위 N% 표시.

### 2-1. 정규화 공식

- raw 점수 = base 40 + 시그너 weight 합산 (clamp 0~100)
- normalized = percentile stepwise 매핑 (상위 1%→99, 상위 15%→90, 상위 30%→78, 상위 50%→62)
- 같은 percentile 사용자는 같은 점수 → 일관성

분포 시뮬레이션: 2008~2020 × 365일 × 12시간 슬롯 × 2성별 = **113,976 sample**

| 항목 | 분포 평균 | 분포 stddev |
|---|---|---|
| 학자형 | 71.8 | 16.6 |
| 시험장 강함 | 65.6 | 12.9 |
| 끈기·꾸준 | 81.8 | 13.1 |
| 사고력 | 62.4 | 11.5 |
| 표현·발표 | 65.6 | 16.1 |

## 4. 점수 시스템 명리적 근거

### 4-1. 한국 명리학 통설 기반

- **관인상생**: 관성(시험·자격) + 인성(학문) 흐름 = 학자형 핵심 [명리학회·다시 배우는 사주명리]
- **학당귀인 / 문창귀인 / 천을귀인**: 학문 인연 3종 길성
- **신왕 + 일주 강**: 체력·자기주도·시험 본질
- **양인격·건록격·비견격**: 추진력·자수성가 본질
- **화개살**: 예술·창작 가장 강한 시그너
- **천의성·백호대살**: 의약·치과 본질

### 4-2. 분포 시뮬레이션 모집단

2008~2020년 양력 × 365일 × 12시간 슬롯(2시간 단위) × 남·녀 = 113,976 조합. 일진·시진은 균등 분포라 한국 모집단과 큰 편향 ✗.
