## 2. 명리학 진영의 분석 (학술 기반)

### 2.1 핵심 선행 연구

| 연구 | 결론 | 한계 |
|------|------|------|
| **자평진전 34장 (고전)** | 격국 + 용신으로 직업 적성 결정 | 현대 직업 분류 체계 부재 |
| **십성 10유형 직업론 (삼명통회)** | 십성별 성향 → 직업 매핑 (비견=자영, 식상=예술, 정재=경영 등) | 단순화 위험 (격국·대운 무시) |
| **정형/편형/혼합형 이론** | 정관·정재·정인 다수 = 안정직장형 / 편관·편재·편인 = 위험감수형 | 모든 사주에 적용 (방향성과 독립) |
| **교사 직업군 연구 (최영선 2004, n=224)** | 교사 만족도는 사주 격국·용신·십성 일치 시 77% | 단일 직업군만 검증 (일반화 제한) |
| **초등 진로적성 × 명리 연구 (서울, n=24)** | 음양오행·십성·격국과 진로흥미 일부 상관 | 표본 극히 작음 (신뢰도 낮음) |

### 2.2 명리학자의 권장

**핵심**: "십성 개수 카운트로 방향성을 정하면 안 된다"

- **격국·용신 우선** — 같은 식신 3개라도 식신격 성격(成格) vs 파격(破格)에 따라 학문형 vs 비제도권으로 갈림
- **대운·운세 필수** — 청소년기 대운이 천성을 발현시키는 조건 제공
- **신살은 보조** — 현침살·도화·화개는 **조건부** 시그너 (기본 격국·십성이 약하면 발현 X)
- **정편 배합** — 모든 사주에 "안정형(정)/위험형(편)/혼합형"으로 분류 필요 (별도 차원)

**명리학자 우려 5가지**:
1. 시그너 폭증 (학운 14 + 방향성 8 = 22) → 자평진전 원칙 위반
2. 속서식 1대1 매칭 ("상관=예술") 무비판 수용
3. N=11 외부 검증 없이 신뢰도 주장
4. 격국·용신 무시, 십성 카운트만 의존
5. "유학·역마형" 같은 현대 카테고리의 자의적 추가

## 3. 사회과학 진영의 분석 (교육·심리학 기반)

### 3.1 핵심 선행 연구

| 연구 | 결론 | 의의 |
|------|------|------|
| **Holland RIASEC (글로벌 표준)** | 6 직업흥미유형: 실재(R)·탐구(I)·예술(A)·사회(S)·기업(E)·관습(C) | 한국 커리어넷·진로상담 표준 채택 |
| **한국 청소년 통계청 (2017, n=?)** | 직업선택 1순위 요인: "적성·흥미" 36.3% | 사주 점수 단독 결정 낮음 |
| **Big5 × Holland 고등학생 연구 (n=1,665)** | 개방성 ↔ 예술형/탐구형, 성실성 ↔ 기업형/관습형 유의 상관 | 성격과 진로흥미 연결 실증 |
| **KCI 통합 연구 "사주명리학과 Holland 진로이론의 융합"** | **사주는 자기보고형 검사의 한계를 보완할 수 있다** | 사주는 단독 도구 ❌, 보완 도구 ✓ |
| **사회인지 진로이론 (meta-analysis)** | 진로 결정 = 흥미 + 능력 + 가치관 + 환경 + 부모 자원 상호작용 | 단일 시그너 결정론 부정 |

### 3.2 사회과학자의 권장

**핵심**: "명리학 시그너를 사회과학 언어로 번역·검증하라"

- **RIASEC 매핑 필수** — 사주 십성을 Holland 6가지에 느슨하게 대응. 사용자가 외부 검사 결과와 비교 가능
- **자기보고형 검사와 병행** — 사주만으로 진로 단정 금지 (부모 기대, 자녀 자기 인식 무시)
- **환경 조건 명시** — 부모 학력·언어·국제화 정도 + 청소년기 대운 발현 필수
- **prospective validity 낮음** — 성인 만족도는 사주와 일부 상관 가능하나, **미성년 미래 직업 예측은 종단 데이터 부족**

**사회과학자 우려 5가지**:
1. 자기보고형 검사 없이 사주만 진단 (KCI 활용 모델 위반)
2. "당신 자녀는 X형 사주" 단정 출력 (진로는 다변량 결정)
3. 30 × 10 = 300 셀, N=11 적용 (셀당 0.036명 → 통계적 무의미)
4. 부모 자원·경제·환경 변수 무시
5. 청소년 적성 예측의 종단 검증 부재

## 5. 최종 권장안: 학운과 완전 분리된 방향성 v3

### 5.1 설계 원칙

```
[Layer A: 학운 30 티어]
  강도: 1-1 (최약) ~ 10-3 (최강)
  정의: 제도권 학업 진입·유지 가능성
  출력: "상위 25% 구간 (4-1)" 등 사실 표현

[Layer B: 정편 배합 (신규 메타)]
  분류: 안정형 / 위험형 / 혼합형 (3가지)
  기준: 정정·정편 비율 (모든 사주에 적용)
  용도: 직장선호 vs 자영업 성향 추정
  부담: 시그너 추가 없음 (단순 분류)

[Layer C: 방향성 10개]
  분류: 10 카테고리 (학자·과학·의약·경영·예술·교육·공무·글로벌·실무·창업)
  판별: 격국·용신 도출 → 10가지 대응 (십성 카운트 ❌)
  표시: 강·중·약 3단계 강도 (점수 합산 ❌)
  언어: RIASEC 코드 병기 (사회과학 호환)

[Layer D: 발현 조건]
  환경: 부모·학교·언어·경제 조건
  운세: 청소년기 대운(11-22세) 흐름
  표현: "조건 충족 시 발현 가능" (단정 금지)

[Layer E: 메타 정보]
  신뢰도: calibration N=11, 외부 검증 진행 중
  학파: 자평진전 + 조건부 신살 (명시)
  보완: Holland·Big5·학교 진로상담 병행 권장
```

혼합형 — 안정과 위험 균형 (직장·자영 모두 가능)

[방향성]
  ★★★ 학자·인문형 (정인격 발달, RIASEC: I)
  ★★☆ 경영형 (정재 보강, RIASEC: E)
  ★☆☆ 예술형 (식상 약, RIASEC: A)

## 8. 최종 체크: "학운과 방향성 분리"가 옳은 이유

### 논리적 근거

1. **차원 분석** — 학운은 "높이(강도)", 방향성은 "방향(벡터)"
   - 높이 3 + 동쪽 vs 높이 3 + 북쪽 → 완전히 다른 진로
   
2. **명리학적 근거** — 격국·용신이 진로를 결정, 신강신약이 강도를 결정
   - 신강(학운 높음) + 정재 = 상위권 경영
   - 신강(학운 높음) + 편인 = 상위권 연구
   - → 신강이 같아도 용신이 다르면 방향 다름
   
3. **사회과학적 근거** — Holland 진로이론
   - 학업 능력(학운) ≠ 진로 흥미(방향성)
   - 능력 고를 수 있고 흥미 낮은 학생도 많음
   - → 독립 축으로 봐야 정합성 높음
   
4. **UI/UX 근거** — 사용자 이해도
   - "학운 4-1 + 방향성 학자형" vs "학운×방향성 매트릭스 셀 (4-1, 학자형)"
   - 전자가 명확하고 발현 조건도 따로 설명 가능
   - → 분리가 사용자에게 더 직관적
