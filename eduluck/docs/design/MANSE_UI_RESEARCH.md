## 1부. 학운 — 명리에서 어떤 수치를 봐야 하는가

자녀 학운(學運)을 풀 때 명리 핵심은 **"머리 · 자리 · 사람 · 흐름"** 네 축.

### 1.1 머리 — 학문의 그릇 (십성 3종 + 격국)

| 십성 | 학운 의미 | 강할 때 | 약할 때 |
|---|---|---|---|
| **인성(印星)** — 정인·편인 | 학문의 뿌리·어머니·스승·문서 | 책상 앞에 오래 앉음, 깊이 파는 공부 | 동기 부재, 문서·자격 인연 약함 |
| **관성(官星)** — 정관·편관 | 시험·합격·체계·규율 | 시험 결과로 직결, 입시 강함 | 자기 통제·마감 약함 |
| **식상(食傷)** — 식신·상관 | 표현·발표·창의·논리 | 말·글로 풀어내는 힘, 발표·면접 강함 | 입력은 되나 출력 막힘 |

- **최고 구조 — 관인상생(官印相生)**: 관성이 인성을 생해주는 흐름. "벼슬 사주". 시험·학문 모두에서 성취 가능.
- **주의 — 인성 과다**: 식상을 눌러 "지식은 많지만 표현 막힘", "어머니에 의존적".
- **격국(格局)**: 월령(월지) 기준 사주의 큰 틀. 정관격·인성격·식신격 = 학문형. 비견격·건록격 = 자기 주도형. 재성격 = 실용형.

### 1.2 자리 — 일간이 어디에 서 있는가 (12운성)

일간(나)이 각 지지에서 어떤 에너지 상태인지. 특히 **월지·일지·시지**의 12운성이 결정적.

- **강한 자리** (학운 유리): 장생 · 관대 · 건록 · 제왕
- **약한 자리** (보완 필요): 병 · 사 · 묘 · 절 · 태

특히 **월지 건록** = "스스로 자리 잡는 힘", **시지 관대** = "옷을 갖춰 입고 세상에 나서는 자리".

### 1.3 사람 — 학운에 작용하는 귀인·살 (신살)

**공부 4귀인**:
| 신살 | 의미 |
|---|---|
| 문창귀인(文昌貴人) | 글공부·총명. 학습능력·추리력·발표력. 신왕 + 형충공망 없을 때 빛남 |
| 학당귀인(學堂貴人) | 교육기관·스승 인연 |
| 문곡귀인(文曲貴人) | 글·예술·연구 깊이 (편인 기운) |
| 천을귀인(天乙貴人) | 사주 최고 길성. 시험·결정적 순간에 도움 |

추가:
- **공망(空亡)** — 학운 자리 공망이면 "노력 대비 결과 허탈"
- **형·충·파·해** — 자리 갈등 (신사형·축술미형 등은 학업 지구력에 영향)

### 1.4 흐름 — 언제 (대운·세운)

- **인성 대운** → 학문 깊이, 자격·입시 성취
- **관성 대운** → 시험·합격 직결 (청소년기 정관 대운 = 입시 성공률 ↑)
- **재성 대운** → 인성을 극함 → **청소년기 재성 대운은 학업 흔들림** → 환경 설계 필수
- **식상 대운** → 표현력·발표력 폭발 (예체능·표현 진로 유리)
- **세운(歲運)**: 시험 해 세운이 인성·관성이면 합격 ↑

### 1.5 어머니-자녀 — 모자(母子) 합

자녀 사주에서 **어머니 = 인성**.
- 어머니 일간이 자녀 일간을 생(生) → 자연스러운 인성 작용
- 어머니가 자녀의 식상 → 키워서 표현시키는 자리
- 어머니가 자녀의 재성 → 자녀 인성을 극해 학업 흔들리는 자리

### 1.6 오행 균형

| 오행 | 학운 의미 | 부재 시 |
|---|---|---|
| 木 | 끈기·뿌리·성장 | 지구력 약, 정서 안정 어려움 |
| 水 | 지혜·암기·논리 | 암기·논리 약 |
| 火 | 표현·열정 | 발표·외향성 약 |
| 金 | 결단·실행 | 결과 못 맺음 |
| 土 | 신뢰·실천 | 꾸준함 약 |

부재 오행 = 용신 보완 방향.

### 학운 핵심 체크리스트 (UI 필수 노출)

```
1. 4기둥 (천간·지지, 한자+한글)
2. 일간 (강조)
3. 십성 (각 기둥별 — 인성·관성·식상이 학운에 결정)
4. 12운성 (각 지지별, 일간 기준 — 강한 자리/약한 자리)
5. 격국 (월령 기준)
6. 신살 — 공부 4귀인 (문창·학당·문곡·천을) 강조
7. 공망 (학운 자리 공망 여부)
8. 합·충·형·파·해 (자리 갈등)
9. 오행 분포 + 부재
10. 대운 흐름 (현재 + 다음)
11. 세운 (현재)
12. 어머니-자녀 인성/십성 합

[학운 특화 가공 — 어머니가 알아볼 수 있게]
- "학운 3종 비중": 인성·관성·식상 막대
- "공부 4귀인 보유표": 4종 ●○ 체크
- "12운성 학운 자리": 월지/일지 강약 한 줄
- "관인상생 여부": ✓ / 보완 필요
```

## 2부. 만세력을 "전문가스럽게" 보여주는 법

### 2.1 국내 만세력 앱 공통 패턴

| 앱 | 강점 | 시각 시그니처 |
|---|---|---|
| 포스텔러 만세력 | 명식·오행·일진·대운이 한 흐름. 그래프 직관. 한자+한글 동시. | 명식판 카드 → 오행 막대 → 대운 가로 띠 |
| 8자어때 | 8자 구조 빠르게 확인하는 단순함 | 큰 4기둥 표 + 최소 정보 |
| 천을귀인 만세력 | 신살(천을·문창·홍염) 전면 노출 | 신살 배지 강조 |
| 정해 만세력 | 사주팔자 각 글자 옆에 십성/12운성/지장간 3줄 라벨 | 글자 옆 세 줄 |

**공통 결론**: "전문가 느낌"은 **데이터 농도**에서 옴. 표 하나에 4기둥 + 십성 + 12운성 + 지장간 + 신살 + 공망 + 합충까지 압축 = 종이 명식지의 전통 그대로.

### 2.2 정통 명식판(命式盤) 구조

```
       시주        일주        월주        년주     ← 헤더 (오른쪽이 년)
    ┌────────┬────────┬────────┬────────┐
십성│  편관   │  (나)   │  정관   │  비견   │  ← 천간 옆 십성
천간│  壬     │  丙*    │  癸     │  丙     │  ← 일간 강조
    │  임     │  병     │  계     │  병     │
지지│  辰     │  申     │  巳     │  申     │
    │  진     │  신     │  사     │  신     │
십성│  식신   │  편재   │  비견   │  편재   │  ← 지지 옆 십성
12운│  관대   │  병     │  건록   │  병     │  ← 일간 기준 12운성
지장│ 을계무  │ 무임경  │ 무경병  │ 무임경  │  ← 지장간
신살│ 화개·  │ 문창·  │ 건록·  │ 문창·  │  ← 각 기둥 신살
    │ 공망   │ 백호   │ 겁살   │ 백호   │
    └────────┴────────┴────────┴────────┘
                                          ← 공망 ◌ 표시
[합·충·형] 신사합(수) · 신신진 삼합(수국) · 신사신 형
[격국] 월지 사화 + 일간 병화 = 건록격
[납음] 일주 병신 = 산하화(山下火)
[용신] 木 (완전 부재)
[오행] ●●● 火3  ●● 金2  ●● 水2  ● 土1  ○ 木0
[대운] 8세 갑오 → 18세 을미 → 28세 병신 → ... (현재 ★)
[세운] 2026 병오 ★
```

### 2.3 "전문가스러움" 시그널 8가지

1. **명식판 표 (4기둥)** — 천간 위 / 지지 아래. 한자+한글 동시.
2. **일간 색상 강조** — 보조색(골드). ✓ 현재 적용됨
3. **각 기둥별 십성 라벨** — 천간 옆 + 지지 옆. **가장 큰 전문가 시그널**.
4. **12운성 라벨** — 일간 기준 각 지지의 12운성.
5. **지장간** — 지지 아래 작은 글씨로 2~3글자.
6. **신살 배지** — 각 기둥별 + ★ 강조 (4귀인 색 차별화).
7. **공망 ◌ 마크** — 공망 지지에 작은 동그라미.
8. **합·충·형·파·해 라인** — 기둥 사이 선 또는 별도 박스.

### 2.4 추가 시각 자산

- 오행 분포 막대/방사형 그래프 (5색)
- 대운 가로 띠 (10년 단위, 현재 강조)
- 세운 마커 (현재 년 강조)
- 격국 · 용신 · 납음 (명식판 아래 한 줄씩)
- 관인상생 등 구조 진단 (한 줄)

### 2.5 어머니에게 "쉽게 + 전문가스럽게" — 두 층 구조

**상층 (Easy Layer) — 학운 카드 4종**
- 본질 카드 — 일간 + 격국 + 납음
- 학운 3종 비중 카드 — 인성·관성·식상 막대 + "관인상생 보여요"
- 공부 4귀인 카드 — 문창·학당·문곡·천을 보유표
- 12운성 학운 자리 카드 — 월지·일지의 12운성 한 줄

**하층 (Pro Layer) — 정통 명식판 (접고 펴기)**
- "정통 만세력 자세히 보기 ▾" 토글
- 펼치면 §2.2 표 전체 노출

이 두 층 패턴이 **"우리가 인터넷 검색 가능한 정통 명리를 기반으로 풀이한다"**는 시그널을 즉시 줌. 어머니는 평소엔 상층만 보지만, "근거가 뭐냐" 궁금할 때 펼쳐서 검증 가능.

## 3부. eduluck 적용 권고안

### 3.1 현재 상태 (PalcaTable.tsx)

| 항목 | 현재 | ManseResult 데이터 |
|---|---|---|
| 4기둥 표 | ✓ 한자만 | yearPillar 등 |
| 일간 강조 | ✓ 골드 | dayPillar |
| 십성 | ✗ | **계산 모듈 신규** |
| 12운성 | ✗ | **계산 모듈 신규** |
| 지장간 | ✗ | `jijanggan` (이미 있음) |
| 신살 배지 | △ (strong만) | `shensha.{year,month,day,hour}Pillar` |
| 공망 | ✗ | 신살 계산에 포함 확인 필요 |
| 합·충·형·파·해 | ✗ | `hapchunh.summary` |
| 오행 그래프 | △ 텍스트 | `elementCounts` |
| 대운 띠 | ✗ | `luckCycles.daeun` |
| 세운 | ✗ | `luckCycles.sewun` |
| 격국·납음 | ✗ | **계산 모듈 신규** |
| 용신 | ✗ | `yongsin` |

### 3.2 신규 계산 모듈 4종

- `lib/manse/sipsin.ts` — 일간 기준 각 천간·지지의 십성 (10가지)
- `lib/manse/unsung.ts` — 일간 기준 각 지지의 12운성
- `lib/manse/gyeokguk.ts` — 월령 기준 격국
- `lib/manse/napum.ts` — 일주 납음오행 (60갑자)

### 3.3 구현 우선순위 (Phase A→E)

| Phase | 작업 | 결과 |
|---|---|---|
| A | 계산 모듈 4종 (sipsin·unsung·gyeokguk·napum) + ManseResult 확장 | 데이터 확보 |
| B | PalcaTable 확장: 십성·12운성·지장간·공망 라벨 추가 | 명식판 1차 |
| C | 명식판 하단: 합충·격국·납음·용신·오행 막대·대운 띠·세운 | 명식판 완성 |
| D | 학운 특화 카드 4종 (본질·3종비중·4귀인·12운성자리) + 어머니-자녀 합 카드 | 상층 완성 |
| E | v3 prompt 재조정: LLM 자체 계산 → 모듈 계산값을 user message에 주입 | 정확도 ↑, 토큰 ↓ |

Phase E까지 가면 v3 prompt 토큰 ~2배 증가도 해소 (LLM이 격국·12운성·납음 자체 계산할 필요 없음).
