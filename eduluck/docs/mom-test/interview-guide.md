# mom test 인터뷰 가이드

> 친구들에게 eduluck을 풀어준 후, 진단 끝나고 3분 정도 카톡/통화로 묻는 질문 4개.
> Mixpanel은 *행동*을 측정하고, 이 인터뷰는 *왜* 그렇게 행동했는지를 측정한다.

## 보낼 때 안내 (카톡 메시지 예시)

```
[보낼 메시지]
사주 학운 진단 만들어봤는데, 한번 풀어볼래?
무료고 5분~10분 정도 걸려.

링크: https://four-pillars-alpha.vercel.app

자녀 생년월일·출생시간만 있으면 돼.
다 본 후에 4가지만 짧게 물어볼게.
```

표본 분리 (NPS·결제 의향 부풀음 방지):
- 가까운 친구 그룹과 친구의친구·잘 모르는 어머니 그룹을 따로 표시
- 데이터 해석 시 **친구의친구·잘 모르는 사람 응답만 진짜 신호**로 채택

## 인터뷰 4문항 (3분)

진단 끝나고 카톡/통화로 묻는다. 미리 보낼 필요 없음, 자연스러운 대화로.

### Q1. 구체적으로 맞다고 느낀 부분 한 가지만 말해줄 수 있어?

**측정 의도**: "신기하다"는 만족 신호가 아니다. 구체 사례를 댈 수 있어야 진짜 적중.

**좋은 답**: "강점에 '글을 잘 정리한다'는 부분 — 우리 애가 진짜 일기 잘 써.", "어머니-자녀 합에서 부딪힌다고 한 부분 맞아."
**약한 답**: "신기하더라", "재밌었어", "다 그럴듯해 보였어"

→ 약한 답만 나오면 풀이 품질이 약함. 광고 금지 신호.

---

### Q2. 정밀 진단까지 본 후, 19,900원이면 결제할 의향이 있었어? 솔직히.

**측정 의도**: 행동(`payment_info_submit`)이 부풀려졌는지 검증. "Yes"라고 한 사람 중 실제 결제까지 갈 사람 비율.

**Yes 인 경우 추가**:
- "어떤 부분이 결제할 만하다고 느꼈어?"

**No 인 경우 추가** (이게 더 중요):
- "어디서 막혔어? 가격이 비싸서? 신뢰가 부족해서? 내용이 부족해서?"
- 답을 3 중 하나로 분류:
  - **가격**: 콘텐츠는 좋은데 19,900이 부담 → 가격 조정 검토
  - **신뢰**: 사주 자체에 회의 → 타겟 mismatch
  - **내용**: 풀이가 짧거나 일반적 → 콘텐츠 보강

**조건부 인 경우 추가**:
- "어떤 조건이면 결제할 것 같아?" (PDF 출시, 가족할인, 친구 추천 등)

---

### Q3. 이걸 친구한테 보낸다면 누구에게 보낼 것 같아? 왜?

**측정 의도**: K-factor의 정성 신호. "공유 의향"보다 *구체적 대상*이 나오는지가 신호.

**좋은 답**: "초등 자녀 둔 OO 언니. 진로 고민 많아하니까.", "맘카페 △△ 단톡방"
**약한 답**: "음... 누구든?", "보낼 사람 없을 듯", "글쎄"

→ 구체 대상이 안 나오면 organic 확산 어려움. 광고 의존도 ↑.

---

### Q4. 끝까지 안 봤거나, 도중에 멈춘 부분이 있었어?

**측정 의도**: Mixpanel funnel에서 보이지 않는 *왜* 멈췄는지의 이유.

**자주 나올 답**:
- "긴 텍스트가 부담스러웠어" → 가독성·구조 보강
- "어머니 사주까지 입력하라는 게 부담" → 가족 정보 UX 검토
- "어디까지 봐야 끝인지 모르겠어" → progress 표시 보강
- "Part2가 너무 비슷해" → 콘텐츠 차별화

## GO/HOLD/KILL 판정 표

mom test 완료 후 funnel + 인터뷰 종합.

| 단계 | 분모 | 🟢 GO | 🟡 HOLD | 🔴 KILL |
|---|---|---|---|---|
| 입력 완료 | 진입자 | 80%+ | 60-80% | 50%- |
| 무료 진단 80% 스크롤 | 입력 완료자 | 70%+ | 40-70% | 30%- |
| 구체 적중 사례 진술 (Q1) | 인터뷰 응답자 | 70%+ | 40-70% | 30%- |
| 결제 게이트 도달 (`premium_start_click`) | 무료 진단 본 사람 | 40%+ | 20-40% | 15%- |
| **PDF 사전 예약 실 제출 (`payment_info_submit`)** | Part2 완독자 | 10%+ | 3-10% | 3%- |
| 영역 cap 도달 (`section_cap_reached`) | 진단 시작자 | 20%+ | 10-20% | 5%- |
| 두 번째 자녀 자발 입력 | 진단 시작자 | 20%+ | 10-20% | 5%- |

**판정 규칙**:
- **Soft launch GO** (카카오페이 결제 인프라 도입 → 실 결제 받기): KILL 0-1개 AND `payment_info_submit` 실 제출자 3명 이상 (절대 수)
- **광고 GO는 여기서 판단 X** — soft launch N=50-100 실 결제 CVR과 환불율로 판단
- **KILL**: 2개 이상 KILL — 콘텐츠 / UX 재작업, mom test 다시

## 함정 (피하라)

- 가까운 친구 응답만 보면 NPS·결제 의향이 +20점 부풀어 보임 → 광고 켜고 후회. **친구의친구·잘 모르는 어머니 그룹 응답만 진짜 신호**
- "신기하다" = 만족 신호 아님. Q1에서 구체 사례 안 나오면 KILL
- 가격 인하 충동 금지. Q2에서 "비싸서 안 한다"가 다수여도 *가격*이 아니라 *신뢰·내용* 문제일 수 있음 — 분류 필수
- N=10이면 1-2명 차이로 비율이 흔들림. 표본이 작을 때는 *방향*과 *구체 사유*가 비율보다 더 중요
