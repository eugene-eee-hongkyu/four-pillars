### 0-b. 주요 내부 로직 (1줄씩)

- **만세력 계산:** 자녀·어머니 사주 입력 → 천간·지지·**십성·신살(귀인 등)·12운성·합충형해·대운·세운** 자동 계산
- **AI 진단 호출:** 자녀 사주만(간이, **A4 0.5페이지 ~15~20문장**) / 자녀+어머니 사주(정밀, **A4 1페이지 ~30~40문장**) prompt 차별화
- **학년대별 콘텐츠 톤:** 초저·초고·중·고 4분기 자동 분기 (모두 활성)
- **시간 모름 처리:** 시(時)주 비우고 진단 + 면책 + 비회원 이메일 1개(재진입 리마인더 전용)
- **비회원 세션:** UUID 30일 보존, 회원가입 시 paid 상태·진단 데이터 자동 연결
- **Mock 결제:** 카드 정보 **prefilled placeholder**, "결제하기" 한 탭 완료, 게이트웨이 호출 없음
- **만세력 화면 mini AI 호출:** 화면 10에서 자녀-어머니 관계 1~2줄 mini 분석 (별도 짧은 호출)
- **Mom test 설문:** S1.3(화면 5)·S3.2(화면 11) — MVP 핵심 측정 지표

## 1. A-1 요약 블록 (타겟 확장 반영)

> **핵심 가설:** 학생(초·중·고) 자녀를 둔 30~45세 어머니가, 학년·진로 결정 시점에, 자녀 사주만 입력해 무료 간이 학운 진단을 받은 뒤, 본인 사주를 추가하고 정밀 분석에 결제할 것이다.

```

         [OTP 검증]  [prefilled               [mini AI 호출

 ├── mom test 2차 (가치 점수)

 └── [진단 종료] / [결과 다시 보기]

└────────────────────────┘
```

**4-b. UX 의도**
시간 모름이 정상 옵션 — checkbox로 normalize. 모달 톤 = 면책 + 재진입. 이메일은 명시적 "선택" 강조. CTA "만세력 보기" — 다음이 진단 아닌 만세력 화면임을 시각 명시.

**4-c. 인터랙션**
- 시간 모름 체크 → 모달 자동 오픈, 시간 필드 disabled
- 모달 [확인] → 닫고 main 폼, 이메일 있으면 비회원 세션에 저장
- [만세력 보기] → 화면 4 진입, 만세력 자동 계산

**4-d. 상태**
- 검증: 생년월일 미입력 → [만세력 보기] disabled
- 양력/음력 토글: 음력 선택 시 윤달 옵션 자동
- 출생 지역 default = 서울

## Claude의 적대적 압박 — Kill할 이유 세 가지

1. **만세력 화면(4·10)의 정보량이 학부모 인지 부담을 초과할 위험** — 십성·신살·12운성·합충형해·대운까지 노출은 saju 친화 어머니에게는 신뢰 신호이나, 모르는 어머니에게는 거리감 → 화면 5 진입 전 이탈 발생 가능. 용어 가이드 펼침이 완충이지만 drop-off 측정 필수. 만세력 화면 이탈율이 30% 넘으면 정보 축소 검토.

2. **prefilled 카드 정보로 결제 의향 신호가 "탭 의향"으로 약화** — 카드 입력 friction을 noise로 분리한 의도는 옳지만, 동시에 "실제 결제했다면 카드 꺼낼 의향까지 있었나" 신호도 함께 사라짐. 화면 11의 "실제 결제 의향 1~5점 설문"이 이를 대체해야 하나 자기 보고 편향 큼. **MVP 결과 해석 시 "탭 행위" + "설문 자기 보고"의 결합 신호로 보수적 해석 명문화 필요.**

3. **A4 1페이지 정밀 진단 분량이 모바일 가독성 한계 초과 가능** — 학년대별 가이드 4구간 + 어머니-자녀 합 + 종합 조언 + (고등) 전공·학교 = 1페이지 분량이지만 모바일 스크롤 깊이 큼. 끝까지 읽는 비율 30~40% 추정. 마지막 박힌 설문 응답률 자연 하락 → MVP 측정 지표 오염. **목차/접기 패턴 도입** 검토 (A-3a 단계), 또는 핵심 섹션 hi-light 우선.
