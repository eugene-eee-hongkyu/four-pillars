# 사주 해석 강화

> 훅 4개(일주·오행·대운·신살) + 40문장+ 쉬운 풀이 + 전체 만세력 프롬프트 주입

## 배경 — 기획 결정 요약

기획자와의 대화에서 확정된 방향:

| 항목 | 결정 |
|---|---|
| 해석 길이 | 40문장+ (기존 5~8문장에서 대폭 확장) |
| 훅 4개 (사용자에게 직접 언급) | 일주, 오행 과다·부족, 현재 대운, 강한 신살 1~2개 |
| 내부 근거 (프롬프트 주입, 사용자에게 직접 노출 X) | 십신 분포, 용신, 세부 신살, 월주·년주·시주 |
| 프롬프트 주입 데이터 | 전체 만세력 (4기둥·오행·십신·신살·용신·대운·세운·월운) |
| 쉬운 풀이 원칙 | 각 훅 5~8문장 + 일상 상황 예시 2~3개 반드시 포함 |
| 해석 순서 | 일주 → 오행 → 대운 → 신살 → 고민·패턴 연결 |

**AI 사주의 경쟁 우위**: 대면 역술가나 유튜브는 시간·체력 한계로 이 밀도를 낼 수 없다.
첫 해석부터 30~40문장 규모의 구체 예시를 담아 풀어내는 것이 사주톡의 핵심 차별점.

## 개발 계획

1. **신살 계산 모듈** `lib/manse/shensha.ts` (신규)
   - 도화살·역마살·학당귀인·천의성·암록·문창귀인·양인살·공망 8종
   - 일간·일지·년지 기준 매핑 테이블로 구현
   - 사주 4기둥 전체 스캔 → 기둥별 신살 목록 + `strong` 추천 1~2개 반환

2. **용신 근사 계산** `lib/manse/yongsin.ts` (신규)
   - 억부용신 근사: 오행 비중에서 과다(50%+) → 극하는 오행 = 용신 후보
   - 없는 오행 → 보완 오선 = 용신 후보
   - 단순 룰 기반, 전문 역술 정밀도 불필요 (프롬프트 방향성 제공 목적)

3. **만세력 엔진 확장** `lib/manse/engine.ts`
   - `ManseResult`에 `shensha: ShenshaResult`, `yongsin: YongsinResult` 추가
   - `computeManse()` 내부에서 `calcShensha()`, `calcYongsin()` 호출

4. **프롬프트 전면 개편** `lib/prompts/interpret.ts`
   - 시스템 프롬프트: 훅 4개 순서(일주→오행→대운→신살) + 각 5~8문장 + 예시 2~3개 의무화
   - 총 40문장+ 분량 명시
   - `buildInterpretPrompt()`: 신살·용신·십신·대운·세운·월운 포함 전체 만세력 구조화 주입

5. **interpret API 업데이트** `app/api/interpret/route.ts`
   - `max_tokens`: 1024 → 4096
   - `fullManse` 파라미터 수신 + 프롬프트에 주입

6. **채팅 화면 데이터 전달** `app/chat/page.tsx`
   - `loadProfile().manse` 전체를 interpret API에 `fullManse`로 전달
