# A-0. 사주톡 — 생각을 문서로

> **이 문서의 1차 독자는 나 자신이다.**
> Claude와 AI 빌드 도구는 2차 독자.
> 내 생각을 눈으로 보기 위해 Claude의 도움으로 꺼내 쓴 문서다.

---

## 1. 핵심 가설 한 문장

이직·연애·결혼 고민이 있는 28~34세 여성이, 링크로 받은 웹 사주 서비스에서, 긴 해석을 읽은 뒤 스스로 최대 3번의 추가 질문을 써가며 대화를 완주할 것이다.

## 2. 왜 지금인가

시대가 불안해서 28~34세가 이미 Gemini·GPT로 사주를 본다 — 수요는 입증됨. 하지만 범용 AI는 생시만으로는 만세력 계산이 부정확하다. 사주톡은 정확한 만세력을 먼저 뽑아 프롬프트에 주입하고, 양방향 대화로 되묻는다. 이게 범용 AI 대비 해석 품질의 구조적 상한을 만든다. 웹/앱 사주는 단방향, 오프라인 사주·타로만 양방향인 현 시장에서 대면 경험을 전용 서비스로 온라인에 가져올 타이밍이 지금이다.

## 3. 누가 쓰는가

28~34세 여성, 수도권, 사회생활 5~10년차. 이직·연애·결혼 같은 인생 전환기 결정 앞에 있음. 지금은 Gemini·GPT에 직접 묻거나, 유튜브 역술가 영상 보거나, 무료 앱으로 원국만 봄. MVP 단계에서는 Eugene 주변 지인 10명이 테스터.

## 4. 러프 유즈케이스 메인 라인

사용자가 링크 접속 → 생년월일시와 고민 한 줄 입력 → 반복 패턴 4지선다 1회 답 → AI가 유명 역술가 톤으로 5~8문장 긴 해석 제공 → "더 궁금한 거 최대 3번 물어보실 수 있어요" 안내 → 사용자가 자유롭게 추가 질문 → 정리 응답 받고 종료. 세션 답은 DB에 쌓여 다음 세션 해석에 자동 참조됨.

## 5. MVP 경계

| 항목 | 이번 버전에서 고정 | 배제한 것 |
| --- | --- | --- |
| 제품 1개 | AI 대화형 사주 해석 웹서비스 (생시+고민 입력 → 긴 해석 → 사용자 주도 질문 최대 3회 → 정리) | 타로, MBTI, 관상, 손금, 음성 대화, 모바일 앱 |
| 타겟 세그먼트 1개 | 28~34세 여성, 수도권, 이직·연애·결혼 고민. Eugene 지인 10명 | 남성, 20대 초반, 40대 이상, 지방, 육아·건강·재테크 고민, 모르는 사용자 |
| 목표 행동 1개 | 3번 질문 다 쓰고 정리까지 완주 (보조 지표: 1번 이상 질문 후 완주) | 단순 방문, 생시 입력만, 해석만 읽고 종료, 회원가입, 웨이팅리스트 |

**왜 이렇게 좁히는가** — 10명 지인 테스트라 채널·수익 신경 쓸 필요 없음. "사용자가 긴 해석 후 스스로 세 번이나 더 묻는가"가 "쉽게 풀어주는데 내 얘기네" 검증 축이 작동했는지 판별하는 단 하나의 선명한 지표다.

## 6. Kill / Go / Hold 판정

**Go — A-1로 진입**

근거 3줄:

1. 핵심 가설이 "[누가][언제][뭘]" 형식 명확히 갖춤. 10명 테스트로 검증 가능한 크기
2. "만세력 주입 + 긴 해석 + 사용자 주도 3질문 + 몰입 피크에 부모 생시 요청"이라는 구조적 Edge가 Eugene 머릿속에 이미 구체화돼 있음. A-1로 바로 분해 가능한 수준
3. 10명 테스트라 실패해도 매몰 비용 작음. 기능 검증되면 10만원 소액 마케팅으로 재검증 여지 있음. 지금 A-0에서 더 논의하는 건 비효율

---

## Claude의 적대적 압박 — 지금 이 아이디어를 죽일 이유 세 가지

1. **"GPT로 이미 사주 본다"가 역풍일 수 있음.** 수요 증거인 동시에 "사용자는 공짜로 만족 중"이라는 뜻이기도 함. 지인 10명이 "GPT랑 뭐가 달라요?"에 답이 막히면 서비스 존재 이유 없음. (반박: 만세력 정확도가 구조적 차별점. 체감 가능한지는 테스트에서 확인)
2. **"3번 질문 다 쓰기"가 희소 행동일 가능성.** 10명 중 0~1명만 도달하면 데이터 부족. (반박: 역술가 대면이 시간·횟수로 과금되므로 "3번" 프레이밍은 도메인 관습과 정합. 이상하지 않음)
3. **Eugene 지인 = 립서비스 검증 위험.** 지인은 "좋았어"라고 말하고 실제로 안 씀. 타겟 세그먼트와 지인 집단의 불일치도 별개 문제. (반박: 도메인 오픈되어 있어 기능 검증 후 소액 마케팅으로 재검증 가능)
