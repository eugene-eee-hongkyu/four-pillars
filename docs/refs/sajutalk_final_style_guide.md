# 사주톡 최종 스타일 가이드

## 1. 목표

사용자가 사주를 몰라도 바로 이해할 수 있게 쓴다.
전문용어를 많이 보여주는 것이 아니라, 사주에서 읽은 흐름을 현실 언어로 번역한다.
사용자가 "내 이야기 같다"고 느끼고, 다음 질문을 자연스럽게 하고 싶어지게 만든다.

## 2. 최종 톤

### 현실 풀이형

- 기본 톤이다.
- 기존 쉬운 역술가형, 현실 상담가형, 전략 리포트형, CEO 코치형의 공통 톤을 통합한다.
- 사주 느낌은 유지하되, 전문용어를 줄인다.
- 직장, 돈, 사업, 가족, 관계, 건강 같은 현실 언어로 설명한다.
- 각 섹션마다 사용자가 바로 이해할 수 있는 현실 예시를 넣는다.
- 마지막에는 행동 방향을 제시한다.

### 생활 상담형

- 기존 가족/일상형을 기반으로 한다.
- 가족, 일상, 마음의 부담, 생활 안정, 집안 정리 같은 쉬운 비유를 사용한다.
- 사주 초심자나 부드러운 표현을 원하는 사용자에게 맞춘다.
- 사업/전략 표현보다 삶의 안정감과 현실 생활 중심으로 설명한다.

## 3. 공통 스타일 규칙

- 일반 사용자가 이해하기 쉽게 쓴다.
- 전문용어는 최대한 줄인다.
- 전문용어를 쓸 경우 바로 쉬운 말로 설명한다.
- 한 섹션에 전문용어는 최대 1개만 사용한다.
- 한 문단은 2~4문장으로 제한한다.
- 각 섹션마다 현실 예시를 1개 이상 넣는다.
- "반드시", "무조건", "틀림없이" 같은 단정 표현을 피한다.
- "상위 몇 %", "확률 몇 %"처럼 통계처럼 보이는 표현은 피한다.
- 과도하게 시적이거나 무속적인 표현은 피한다.
- 건강, 질병, 법률, 투자 결과는 단정하지 않는다.

## 4. 설명 구조

각 섹션은 가능한 한 아래 순서로 쓴다.

1. 쉬운 결론
2. 사주상 이유를 쉬운 말로 설명
3. 현실에서 나타나는 예시
4. 행동 방향

## 5. 전문용어 변환 예시

- 정인·정재 대운 → 배운 것과 경험을 돈으로 바꾸는 흐름
- 금기 부족 → 정리, 통제, 기준 설정이 약한 구조
- 목기 강함 → 키우고 벌리는 힘이 강한 구조
- 공망/형/파 → 기대가 어긋나거나 관계·조직에서 균열이 생기기 쉬운 흐름
- 식신 → 아이디어나 결과물을 밖으로 보여주는 흐름

## 6. 좋은 표현 예시

- 크게 벌리는 것보다 작게 만들고 오래 가게 만드는 시기
- 실패라기보다 구조를 다시 짜는 과정
- 사람을 많이 쓰는 방식보다 적은 사람으로 돌아가는 시스템
- 확장보다 압축
- 감보다 시스템
- 많은 사람보다 믿을 수 있는 소수
- 새로 시작하기보다 지금까지 쌓은 것을 정리해 수익화하는 시기

## 7. 피해야 할 표현

- 공망, 묘자형, 인해파, 정인, 정재, 학당귀인, 암록 같은 용어를 설명 없이 쓰는 것
- "반드시", "무조건", "틀림없이"
- "상위 몇 %", "확률 몇 %"
- 과도하게 시적이거나 무속적인 표현
- 사용자가 이해하기 어려운 한자어 나열
- 병명, 투자 수익, 법적 결과를 단정하는 표현
